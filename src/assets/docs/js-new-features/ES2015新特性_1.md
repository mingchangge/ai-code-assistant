ES2015（也称为ES6）是JavaScript语言的一个重要版本，引入了许多新的特性和语法，极大地提升了JavaScript的开发体验和代码可读性。以下是一些主要的ES2015新特性：

## 1. 块级作用域（let、const）：

let和const: 提供了更严谨的变量声明方式，let用于声明块级作用域变量，const用于声明常量。

```javascript
{
  let a = 10
  const b = 20
}
console.log(a) // 报错：a is not defined
console.log(b) // 报错：b is not defined
```

## 2. 箭头函数（Arrow Function）：

箭头函数是一种更简洁的函数表达式语法，它没有自己的this、arguments、super或new.target绑定，并且不能用作构造函数。

```javascript
const add = (a, b) => a + b
console.log(add(1, 2)) // 3
```

## 3. 对象字面量增强

### 1. 属性值缩写（Object Literal Property Value Shorthand）

属性值缩写是一种方便的对象字面量语法，它可以省略属性值和属性名相同的情况。

```javascript
const name = 'lily'
const age = 25
const obj = { name, age }
console.log(obj) // { name: 'lily', age: 25 }
```

### 2. 方法缩写（Object Literal Method Shorthand）

方法缩写是一种方便的对象字面量语法，它可以省略方法名和function关键字。

```javascript
const obj = {
  name: 'lily',
  age: 25,
  sayName() {
    console.log(this.name)
  }
}
obj.sayName() // lily
```

### 3. 计算属性名（Computed Property Names）

计算属性名是一种方便的对象字面量语法，它可以在对象字面量的定义阶段，直接使用方括号 [] 来包裹一个表达式，其计算结果将作为属性名。

```javascript
const name = 'name'
const age = 'age'
const obj = { [name]: 'lily', [age]: 25 }
console.log(obj) // { name: 'lily', age: 25 }
```

### 4. 在对象字面量设置原型

```javascript
const user = {
  name: 'lily',
  greet() {
    console.log(`hello ${this.name}!`)
  }
}
const admin = {
  __proto__: user, //  直接在这里设置原型！
  name: '管理员',
  role: 'admin'
}
console.log(admin.greet()) // hello 管理员!
console.log(admin.role) // admin
console.log(Object.getPrototypeOf(admin) === user) // true
```

### 5. 直接调用原型链上层（父层）的方法

在ES6中，我们可以使用 super 关键字来直接调用原型链上层（父层）的方法。

```javascript
class Animal {
  constructor(name) {
    this.name = name
  }
  sayName() {
    console.log(this.name)
  }
}
class Cat extends Animal {
  constructor(name) {
    super(name)
  }
  sayName() {
    super.sayName()
  }
}
const cat = new Cat('kitty')
cat.sayName() // kitty
```

或结合在对象字面量设置原型

```javascript
const user = {
  name: 'lily',
  greet() {
    console.log(`hello ${this.name}!`)
  }
}
const admin = {
  __proto__: user, //  直接在这里设置原型！
  name: '管理员',
  role: 'admin',
  greet() {
    const parentGreeting = super.greet()
    return `${parentGreeting} I have special permissions.`
  }
}
console.log(admin.greet()) // hello 管理员! I have special permissions.
```

## 4. for...of 循环

for...of循环是一种方便的遍历数组或类数组对象的方式，它可以直接获取数组或类数组对象的元素值，而不需要使用索引。

```javascript
const arr = [1, 2, 3]
for (const item of arr) {
  console.log(item)
}
// 1
// 2
// 3
```

## 5. 模板字符串（Template Literals）：

模板字符串是一种更方便的字符串拼接方式，它使用反引号（`）包裹字符串，并且可以在字符串中嵌入变量和表达式。

```javascript
const name = 'lily'
const age = 25
const info = `My name is ${name}, and I am ${age} years old.`
console.log(info) // My name is lily, and I am 25 years old.
```

## 6. 带标签的模板字面量（Tagged Template Literals）

带标签的模板字面量（Tagged Template Literals）是一种特殊的模板字符串，它可以在字符串中嵌入变量和表达式，并且可以对字符串进行处理。在带标签的模板字面量中，函数名（标签）后面直接跟着模板字面量，而不需要使用括号 `()` 包裹。

```javascript
function tag(strings, ...values) {
  // 自定义处理逻辑
  return /* 处理后的字符串 */
}
const name = 'lily'
const age = 25
const info = tag`My name is ${name}, and I am ${age} years old.`
console.log(info) // My name is lily, and I am 25 years old.
```

### 参数

- `strings`：一个数组，包含了模板字符串中所有的**静态字符串**（即 `${}` 之间的内容）。
- `...values`：一个数组，包含所有动态表达式（即 `${}` 中的值）。

## 7. 解构赋值（Destructuring Assignment）：

解构赋值是一种方便的变量赋值方式，它可以从数组或对象中提取值并赋值给变量。

```javascript
const arr = [1, 2, 3]
const [a, b, c] = arr
console.log(a, b, c) // 1 2 3

const obj = { name: 'lily', age: 25 }
const { name, age } = obj
console.log(name, age) // lily 25
```

## 8. 扩展运算符（Spread Operator）：

扩展运算符是一种方便的数组或对象展开方式，它可以将数组或对象展开为多个参数或元素。

```javascript
const arr1 = [1, 2, 3]
const arr2 = [...arr1, 4, 5, 6]
console.log(arr2) // [1, 2, 3, 4, 5, 6]

const obj1 = { name: 'lily', age: 25 }
const obj2 = { ...obj1, sex: 'male' }
console.log(obj2) // { name: 'lily', age: 25, sex: 'male' }
```

## 9. 函数参数扩展

### 1. 默认参数值（Default Parameter Values）：

默认参数值是一种方便的函数参数赋值方式，它可以在函数调用时省略参数，使用默认值。

```javascript
const add = (a = 0, b = 0) => a + b
console.log(add(1, 2)) // 3
console.log(add(1)) // 1
console.log(add()) // 0
```

### 2. 剩余/不定参数（Rest Parameters）：

在ES6之前的规范中我们大可以使用arguments变量来达到不定参数的判断。
ES6的剩余参数（又称不定参数）使用三个点 (...) 来表示，它允许函数接收不定数量的参数，并将这些参数收集到一个数组中。 不定参数必须是最后一个参数，并且一个函数中只能有一个不定参数。

```javascript
const add = (...args) => args.reduce((a, b) => a + b, 0)
console.log(add(1, 2, 3)) // 6
console.log(add(1, 2, 3, 4)) // 10
```

### 3. 拓展参数

关于拓展参数，其实拓展参数其实一种语法糖，它允许传递一个数组（或者类数组）作为函数的参数，而不需要apply操作，函数内部可以自动将其当前不定参数解析，然后可以获得每一个数组（类数组）元素作为实际参数。

```javascript
function foo(x, y, z) {
  return x + y + z
}
console.log(foo(...[1, 2, 3])) // 6
```

## 10. 类

类是一种方便的对象创建方式，它可以定义对象的属性和方法。

```javascript
class Person {
  constructor(name, age) {
    this.name = name
    this.age = age
  }
  say() {
    console.log(`My name is ${this.name}, and I am ${this.age} years old.`)
  }
}
const p = new Person('lily', 25)
p.say() // My name is lily, and I am 25 years old.
```

## 11. object 新增内置对象API

### 1. Object.assign()

Object.assign() 方法用于将所有可枚举属性的值从一个或多个源对象复制到目标对象。它返回目标对象。

```javascript
const target = { a: 1, b: 2 }
const source = { b: 4, c: 5 }
Object.assign(target, source)
console.log(target) // { a: 1, b: 4, c: 5 }
```

### 2. Object.is()

Object.is() 方法用于判断两个值是否严格相等，它与严格比较运算符（===）的行为基本相同，但是它可以处理一些特殊情况，例如 NaN 和 -0。

1. +0 和 -0 被视为不相等。
2. NaN 和 NaN 被视为相等。

```javascript
console.log(Object.is(NaN, NaN)) // true
console.log(Object.is(-0, 0)) // false
```

#### 3. Object.getOwnPropertyDescriptors()

Object.getOwnPropertyDescriptors() 方法用于获取对象的所有属性描述符，包括不可枚举属性。

```javascript
const obj = { a: 1, b: 2 }
console.log(Object.getOwnPropertyDescriptors(obj))
// {
//   a: { value: 1, writable: true, enumerable: true, configurable: true },
//   b: { value: 2, writable: true, enumerable: true, configurable: true }
// }
```

#### 4. Object.getOwnPropertySymbols()

Object.getOwnPropertySymbols() 方法用于获取对象的所有 Symbol 属性名。

```javascript
const obj = { a: 1, b: 2 }
const sym = Symbol('sym')
obj[sym] = 3
console.log(Object.getOwnPropertySymbols(obj)) // [Symbol(sym)]
```

#### 5. Object.setPrototypeOf()和Object.getPrototypeOf()

- Object.setPrototypeOf() 方法用于设置对象的原型（即内部 [[Prototype]] 属性）。

- Object.getPrototypeOf() 方法用于获取对象的原型（即内部 [[Prototype]] 属性）。

**用途**：在对象创建后动态地改变或读取其原型链，它们是官方推荐的、用于操作原型的标准方法。

```javascript
const obj = { a: 1, b: 2 }
const proto = { c: 3 }
Object.setPrototypeOf(obj, proto)
console.log(obj.__proto__) // { c: 3 }
console.log(Object.getPrototypeOf(obj)) // { c: 3 }
```

## 12. Array 新增内置对象API

### 1. Array.from()

Array.from() 方法用于将类数组对象或可迭代对象转换为数组。

```javascript
const str = 'hello'
const arr = Array.from(str)
console.log(arr) // ['h', 'e', 'l', 'l', 'o']
```

### 2. Array.of()

Array.of() 方法用于创建一个具有可变数量参数的新数组实例，而不考虑参数的数量或类型。它解决了 `new Array()` 的歧义问题。`Array.of(7)` 创建一个具有单个元素 7 的数组，而 `Array(7)` 创建一个 length 为 7 的空数组（这意味着一个由 7 个空槽组成的数组，而不是由 7 个 undefined 组成的数组）。

```javascript
const arr = Array.of(1, 2, 3)
console.log(arr) // [1, 2, 3]
```

### 3. Array.prototype.includes()

Array.prototype.includes() 方法用于判断数组是否包含指定元素，返回一个布尔值。

```javascript
const arr = [1, 2, 3]
console.log(arr.includes(2)) // true
console.log(arr.includes(4)) // false
```

### 4. Array.prototype.find()和Array.prototype.findIndex()

Array.prototype.find() 方法用于查找数组中满足指定条件的第一个元素，并返回该元素。如果没有符合条件的元素，则返回 undefined。

Array.prototype.findIndex() 方法用于查找数组中满足指定条件的第一个元素的索引，并返回该索引。如果没有符合条件的元素，则返回 -1。

```javascript
const arr = [1, 2, 3, 4, 5]
console.log(arr.find(item => item > 3)) // 4
console.log(arr.findIndex(item => item > 3)) // 3
```

### 5. Array.prototype.fill()

Array.prototype.fill() 方法用于将数组的所有元素填充为指定值。

```javascript
const arr = [1, 2, 3, 4, 5]
arr.fill(0)
console.log(arr) // [0, 0, 0, 0, 0]
```

### 6. Array.prototype.copyWithin()

Array.prototype.copyWithin() 方法用于在数组内部浅复制元素，它可以将数组的一部分元素复制到另一个位置，并返回它，不会改变原数组的长度。

Array.prototype.copyWithin() 方法的语法如下：

```javascript
arr.copyWithin(target, start, end)
```

- target：要复制到的目标位置索引。
- start：要复制的起始位置索引（包含）。
- end：要复制的结束位置索引（不包含）。如果未指定，则默认复制到数组末尾。

```javascript
const arr = [1, 2, 3, 4, 5]
arr.copyWithin(0, 3, 4)
console.log(arr) // [4, 2, 3, 4, 5]
```

### 7. Array.prototype.entries()

Array.prototype.entries() 方法用于返回数组的键值对迭代器。

```javascript
const arr = [1, 2, 3]
const iterator = arr.entries()
console.log(iterator.next().value) // [0, 1]
console.log(iterator.next().value) // [1, 2]
console.log(iterator.next().value) // [2, 3]
```

### 8. Array.prototype.keys()

Array.prototype.keys() 方法用于返回数组的键迭代器。

```javascript
const arr = [1, 2, 3]
const iterator = arr.keys()
console.log(iterator.next().value) // 0
console.log(iterator.next().value) // 1
console.log(iterator.next().value) // 2
```

### 9. Array.prototype.values()

Array.prototype.values() 方法用于返回数组的值迭代器。

```javascript
const arr = [1, 2, 3]
const iterator = arr.values()
console.log(iterator.next().value) // 1
console.log(iterator.next().value) // 2
console.log(iterator.next().value) // 3
```

## 13. String 新增内置对象API

### 1. String.prototype.includes()

String.prototype.includes() 方法用于判断字符串是否包含指定子字符串，返回一个布尔值。



### 3. String.prototype.endsWith()

String.prototype.endsWith() 方法用于判断字符串是否以指定子字符串结尾，返回一个布尔值。

## 15. Math 新增内置对象API

### 1. Math 算术运算

#### 1. Math.trunc()

Math.trunc() 方法用于将数字的小数部分截断，返回一个整数。

```javascript
console.log(Math.trunc(123.456)) // 123
console.log(Math.trunc(-123.456)) // -123
```

#### 2. Math.sign()

Math.sign() 方法用于判断一个数的符号，返回一个整数。

```javascript
console.log(Math.sign(123)) // 1
console.log(Math.sign(-123)) // -1
console.log(Math.sign(0)) // 0
console.log(Math.sign(NaN)) // NaN
```

#### 3. Math.imul()

Math.imul() 方法用于执行 32 位整数乘法，返回一个 32 位整数。

```javascript
console.log(Math.imul(2, 3)) // 6
console.log(Math.imul(-2, 3)) // -6
```

#### 4. Math.hypot()

Math.hypot() 方法用于计算多个数的平方和的平方根，返回一个数。

```javascript
console.log(Math.hypot(3, 4)) // 5
console.log(Math.hypot(3, 4, 5)) // 7.0710678118654755
```

#### 5. Math.cbrt()

Math.cbrt() 方法用于计算一个数的立方根，返回一个数。

```javascript
console.log(Math.cbrt(8)) // 2
console.log(Math.cbrt(27)) // 3
```

### 2. Math对数和指数运算

#### 1. Math.log2()

Math.log2() 方法用于计算以 2 为底的对数，返回一个数。

```javascript
console.log(Math.log2(8)) // 3
console.log(Math.log2(16)) // 4
```

#### 2. Math.log10()

Math.log10() 方法用于计算以 10 为底的对数，返回一个数。

```javascript
console.log(Math.log10(100)) // 2
console.log(Math.log10(1000)) // 3
```

#### 3. Math.log1p()

Math.log1p() 方法返回一个数字加 1 后的自然对数 (底为 E), 既log(x+1)。对于接近 0 的数字，此方法比 Math.log(1 + x) 更精确。

```javascript
console.log(Math.log1p(1)) // 0.6931471805599453
console.log(Math.log1p(2)) // 1.0986122886681096
```

#### 4. Math.expm1()

Math.expm1() 方法返回一个数字加 1 后的指数函数值减 1，既e^x - 1。对于接近 0 的数字，此方法比 Math.exp(x) - 1 更精确。

```javascript
console.log(Math.expm1(1)) // 1.718281828459045
console.log(Math.expm1(2)) // 6.38905609893065
```

### 3. Math 双曲函数
