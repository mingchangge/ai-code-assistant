# ES2015（es6）新特性

## 1. 块级作用域（let、const）：

let和const: 提供了更严谨的变量声明方式，let用于声明块级作用域变量，const用于声明常量。

```js
{
  let a = 10
  const b = 20
}
console.log(a) // 报错：a is not defined
console.log(b) // 报错：b is not defined
```

## 2. 箭头函数（Arrow Function）：

箭头函数是一种更简洁的函数表达式语法，它没有自己的this、arguments、super或new.target绑定，并且不能用作构造函数。

```js
const add = (a, b) => a + b
console.log(add(1, 2)) // 3
```

## 3. 模板字符串（Template Literals）：

模板字符串是一种更方便的字符串拼接方式，它使用反引号（`）包裹字符串，并且可以在字符串中嵌入变量和表达式。

```js
const name = 'Terren'
const age = 25
const info = `My name is ${name}, and I am ${age} years old.`
console.log(info) // My name is Terren, and I am 25 years old.
```

## 4. 解构赋值（Destructuring Assignment）：

解构赋值是一种方便的变量赋值方式，它可以从数组或对象中提取值并赋值给变量。

```js
const arr = [1, 2, 3]
const [a, b, c] = arr
console.log(a, b, c) // 1 2 3

const obj = { name: 'Terren', age: 25 }
const { name, age } = obj
console.log(name, age) // Terren 25
```

## 5. 默认参数值（Default Parameter Values）：

默认参数值是一种方便的函数参数赋值方式，它可以在函数调用时省略参数，使用默认值。

```js
const add = (a = 0, b = 0) => a + b
console.log(add(1, 2)) // 3
console.log(add(1)) // 1
console.log(add()) // 0
```

## 6. 扩展运算符（Spread Operator）：

扩展运算符是一种方便的数组或对象展开方式，它可以将数组或对象展开为多个参数或元素。

```js
const arr1 = [1, 2, 3]
const arr2 = [...arr1, 4, 5, 6]
console.log(arr2) // [1, 2, 3, 4, 5, 6]

const obj1 = { name: 'Terren', age: 25 }
const obj2 = { ...obj1, sex: 'male' }
console.log(obj2) // { name: 'Terren', age: 25, sex: 'male' }
```

## 7. 剩余参数（Rest Parameters）：

剩余参数是一种方便的函数参数赋值方式，它可以将多个参数打包成一个数组。

```js
const add = (...args) => args.reduce((a, b) => a + b, 0)
console.log(add(1, 2, 3)) // 6
console.log(add(1, 2, 3, 4)) // 10
```

## 8. 类

类是一种方便的对象创建方式，它可以定义对象的属性和方法。

```js
class Person {
  constructor(name, age) {
    this.name = name
    this.age = age
  }
  say() {
    console.log(`My name is ${this.name}, and I am ${this.age} years old.`)
  }
}
const p = new Person('lily', 25)
p.say() // My name is lily, and I am 25 years old.
```

## 9. 模块化（Modules）：

模块化是一种方便的代码组织方式，它可以将代码分成多个模块，每个模块都有自己的作用域，并且可以导出和导入其他模块的代码。
使用`import`和`export`进行模块化管理。

```js
// math.js
export const add = (a, b) => a + b

// app.js
import { add } from './math.js'
console.log(add(1, 2)) // 3
```

## 10. Promise

Promise是一种方便的异步编程方式，它可以处理异步操作的结果，避免回调地狱。

```js
const p = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('success')
  }, 1000)
})
p.then(res => console.log(res)) // success
```

## 11. 迭代器（Iterators）和生成器（Generators）：

- 迭代器是一种方便的遍历方式，它可以遍历数组、字符串、Set、Map等数据结构。
- 生成器是一种方便的异步编程方式，它可以暂停和恢复执行，并且可以返回多个值。

```js
const arr = [1, 2, 3]
const iter = arr[Symbol.iterator]()
console.log(iter.next()) // { value: 1, done: false }
console.log(iter.next()) // { value: 2, done: false }
console.log(iter.next()) // { value: 3, done: false }
console.log(iter.next()) // { value: undefined, done: true }
```

## 12. 代理（Proxy）和反射（Reflection）：

- 代理是一种方便的对象创建方式，它可以拦截和修改对象的默认行为。
- 反射是一种方便的对象操作方式，它可以在运行时动态地调用对象的方法和属性。

```js
const obj = { name: 'Terren', age: 25 }
const proxy = new Proxy(obj, {
  get(target, prop) {
    console.log(`get ${prop}`)
    return Reflect.get(target, prop)
  },
  set(target, prop, value) {
    console.log(`set ${prop} to ${value}`)
    return Reflect.set(target, prop, value)
  }
})
console.log(proxy.name) // get name, Terren
console.log(proxy.age) // get age, 25
proxy.sex = 'male' // set sex to male
console.log(proxy.sex) // get sex, male
```

## 13. Symbol

在 JavaScript 中，Symbol是 ES6 引入的第六种原始数据类型（其余五种为：Number、String、Boolean、Null、Undefined）（js还包含了Object引用数据类型），用于表示独一无二的值。它的核心特点是 “唯一性”，这使得它在解决命名冲突、创建私有属性等场景中非常有用。

### 一、基本概念与创建方式

`Symbol`通过全局的`Symbol()`函数创建，**不能使用`new`关键字**（因为它是原始类型，不是对象）。

```javascript
// 创建一个Symbol
const s1 = Symbol()
console.log(typeof s1)
// symbol（注意：小写，区分于Object等）

// 可以传入一个字符串作为"描述"（仅用于调试，不影响Symbol的唯一性）
const s2 = Symbol('description')
console.log(s2.toString())
// Symbol(description)
```

**关键特性**：即使描述相同，两个Symbol也不相等（唯一性）。

```javascript
const s3 = Symbol('foo')
const s4 = Symbol('foo')
console.log(s3 === s4)
// false
```

### 二、核心特性

#### 1. 唯一性

这是`Symbol`最核心的特性：**任何两个通过`Symbol()`创建的值都是独一无二的**，无论描述是否相同。  
这解决了传统字符串作为键时可能出现的命名冲突问题（例如不同模块给同一对象添加属性时）。

#### 2. 不可枚举性

当`Symbol`作为对象的属性键时，默认**不会被枚举**（即不会出现在`for...in`、`Object.keys()`、`Object.getOwnPropertyNames()` 或 `JSON.stringify()` 的结果中）。这个特性使得 Symbol 非常适合用来定义对象的内部或元数据属性。

```javascript
const obj = {
  [s3]: 'value', // 用Symbol作为属性键（需用方括号）
  name: '张三'
}

// 遍历对象属性
for (const key in obj) {
  console.log(key) // 仅输出 name（Symbol键不会被遍历到）
}

console.log(JSON.stringify(obj)) // {"name":"张三"}（Symbol键被忽略）
console.log(Object.keys(obj)) // ['name']（同样不包含Symbol键）
console.log(Object.getOwnPropertyNames(obj)) // ['name']（同样不包含Symbol键）
```

如果需要获取对象的Symbol属性，需使用专门的方法`Object.getOwnPropertySymbols()`、`Reflect.ownKeys()`：

```javascript
console.log(Object.getOwnPropertySymbols(obj)) // [Symbol(foo)]（返回所有Symbol键）
console.log(Reflect.ownKeys(obj)) // ['name', Symbol(foo)]（包含所有键，包括Symbol）
```

#### 3. 可作为对象键/属性名

`Symbol`可以作为对象的属性键，包括对象字面量（需用方括号包裹）和类的属性。

```javascript
// 1. 对象字面量中使用
const s5 = Symbol('id')
const user = {
  [s5]: 1001 // 必须用方括号，否则会被当作字符串
}

// 2. 类中使用
class MyClass {
  [Symbol('method')]() {
    return '这是一个Symbol方法'
  }
}
const instance = new MyClass()
console.log(instance[Symbol('method')]) // undefined（注意：这里的Symbol是新创建的，与类中不同）
```

> 注意：访问Symbol属性时，必须使用**同一个Symbol值**（因为Symbol是唯一的）。

#### 4. 不能与其他类型直接运算

`Symbol`不能与字符串、数字等类型进行算术或字符串拼接运算，会报错：

```javascript
const s6 = Symbol('num')
// console.log(s6 + 1); // 报错：Cannot convert a Symbol value to a number
// console.log('symbol: ' + s6); // 报错：Cannot convert a Symbol value to a string
```

但可以通过`toString()`方法转为字符串后再运算：

```javascript
console.log('symbol: ' + s6.toString()) // "symbol: Symbol(num)"
```

#### 5. 转换为布尔值时恒为`true`

`Symbol`转换为布尔值时永远是`true`（不存在“ false ”的Symbol）：

```javascript
console.log(Boolean(Symbol())) // true
if (Symbol()) {
  console.log('执行') // 会执行
}
```

#### 6. 全局共享的 Symbol：Symbol.for() 和 Symbol.keyFor()

虽然 Symbol() 总是创建唯一的 Symbol，但有时我们可能需要在不同的代码文件或作用域中共享同一个 Symbol。为此，ES6 提供了全局 Symbol 注册表。

- `Symbol.for(key)`：根据键名（字符串）创建或获取全局 Symbol。如果键名不存在，则创建新的 Symbol；如果已存在，则返回已存在的 Symbol。
- `Symbol.keyFor(symbol)`：根据全局 Symbol 获取其对应的键名（字符串）。如果 Symbol 不是全局 Symbol，则返回 `undefined`。

```javascript
// 创建一个全局Symbol（如果不存在则创建，否则返回已存在的Symbol）
const s7 = Symbol.for('globalSymbol')
console.log(s7) // Symbol(globalSymbol)

// 获取全局Symbol的描述（如果不存在则返回undefined）
console.log(Symbol.keyFor(s7)) // "globalSymbol"
```

### 三、内置Symbol值（Well-known Symbols）

ES6 还提供了一系列内置的、全局可用的 "Well-Known Symbols"。这些 Symbol 作为 Symbol 对象的静态属性存在，例如 `Symbol.iterator`、`Symbol.toPrimitive` 等。 它们允许开发者通过在自己的对象上定义这些 Symbol 属性，来“钩入”并自定义 JavaScript 语言的内部行为

常见的内置Symbol：

| 内置Symbol           | 作用                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `Symbol.iterator`    | 定义对象的默认迭代器（使对象可被`for...of`遍历）                   |
| `Symbol.toStringTag` | 自定义对象的`toString()`返回值（如`[object Array]`中的`Array`）    |
| `Symbol.hasInstance` | 定义`instanceof`运算符的行为（如`obj instanceof Class`的判断逻辑） |
| `Symbol.species`     | 定义衍生对象的构造函数（如数组切片返回新数组时的构造函数）         |
| `Symbol.toPrimitive` | 定义对象转换为原始值的逻辑（如`obj + 1`时的转换规则）              |

#### 示例：使用`Symbol.iterator`使对象可迭代

<font color='blue'>默认情况下，普通对象不能被`for...of`遍历（有疑问，解释在后面）</font>，但可以通过`Symbol.iterator`定义迭代器：

```javascript
const iterableObj = {
  data: [1, 2, 3],
  // 定义迭代器
  [Symbol.iterator]() {
    let index = 0
    return {
      next: () => {
        if (index < this.data.length) {
          return { value: this.data[index++], done: false }
        } else {
          return { done: true }
        }
      }
    }
  }
}

// 现在可以用for...of遍历
for (const item of iterableObj) {
  console.log(item) // 1、2、3
}
```

#### 示例：用`Symbol.toStringTag`自定义`toString()`结果

默认情况下，对象的`toString()`返回`"[object Object]"`，可通过`Symbol.toStringTag`修改：

```javascript
const myObj = {
  [Symbol.toStringTag]: 'MyCustomObject'
}
console.log(myObj.toString()) // [object MyCustomObject]
```

### 四、应用场景

#### 1. 避免对象属性名冲突

当多个模块需要给同一个对象添加属性时，用`Symbol`作为键可以避免命名冲突（因为Symbol是唯一的）。

```javascript
// 模块A
const moduleAKey = Symbol('id')
obj[moduleAKey] = 'A模块的数据'

// 模块B
const moduleBKey = Symbol('id') // 即使描述相同，也是不同的Symbol
obj[moduleBKey] = 'B模块的数据' // 不会覆盖模块A的数据
```

#### 2. 创建“私有”属性

虽然JavaScript没有真正的私有属性，但`Symbol`属性默认不可枚举，且需要通过具体的Symbol值才能访问，可模拟私有属性（避免被意外修改）。

```javascript
const privateKey = Symbol('private')

class User {
  constructor(name) {
    this.name = name
    this[privateKey] = '私有信息' // 模拟私有属性
  }

  getPrivate() {
    return this[privateKey] // 只能通过类的方法访问
  }
}

const user = new User('张三')
console.log(user[privateKey]) // 能访问到（并非真正私有），但不容易被意外操作
console.log(user.getPrivate()) // "私有信息"
```

#### 3. 定义对象的特殊行为

通过内置Symbol（如`Symbol.iterator`、`Symbol.toPrimitive`）自定义对象的默认行为，实现更灵活的逻辑。

### 总结

`Symbol`的核心是“唯一性”，主要用于：

- 解决属性名冲突；
- 模拟私有属性；
- 自定义对象的内置行为（通过内置Symbol）。

它的不可枚举性和唯一性，让它在复杂场景中（如多模块协作、框架开发）非常实用。

## 14. 新增数据结构：

`Map`、`Set`、`WeakMap`、`WeakSet`是新引入的四种集合类型数据结构，它们在存储数据和使用场景上各有特点。下面分别详解：

### 一、Map

`Map`是**键值对的集合**，类似对象，但键的类型更灵活（可任意类型）。

#### 核心特点：

- 键可以是任意类型（字符串、数字、对象、函数等），而普通对象的键只能是字符串或`Symbol`。
- 键是唯一的（重复设置会覆盖）。
- 有明确的大小（`size`属性），可直接获取键值对数量。
- 可遍历（支持`for...of`、`forEach`等），遍历顺序与插入顺序一致。

#### 常用方法：

| 方法/属性           | 说明                                                                         |
| ------------------- | ---------------------------------------------------------------------------- |
| `new Map()`         | 创建空Map（可传入二维数组初始化，如`new Map([[key1, val1], [key2, val2]])`） |
| `map.set(key, val)` | 添加/修改键值对（返回Map本身，支持链式调用）                                 |
| `map.get(key)`      | 获取键对应的值（不存在返回`undefined`）                                      |
| `map.has(key)`      | 判断是否存在该键（返回布尔值）                                               |
| `map.delete(key)`   | 删除指定键（返回布尔值，表示是否删除成功）                                   |
| `map.clear()`       | 清空所有键值对                                                               |
| `map.size`          | 键值对数量                                                                   |

#### 遍历方式：

```javascript
const map = new Map([
  ['name', '张三'],
  ['age', 20]
])

// 1. 遍历键
for (const key of map.keys()) {
  console.log(key) // 'name'、'age'
}

// 2. 遍历值
for (const val of map.values()) {
  console.log(val) // '张三'、20
}

// 3. 遍历键值对（默认）
for (const [key, val] of map) {
  console.log(key, val) // 'name' '张三'、'age' 20
}

// 4. forEach
map.forEach((val, key) => {
  console.log(key, val)
})
```

#### 适用场景：

- 需要非字符串类型作为键（如用对象做键）。
- 需要频繁增删键值对并关注数量（`size`属性）。
- 需要保持插入顺序并遍历。

### 二、Set

`Set`是**唯一值的集合**（无重复值），类似数组，但元素不可重复。

#### 核心特点：

- 元素唯一（重复添加会被忽略）。
- 元素可以是任意类型。
- 有明确的大小（`size`属性）。
- 可遍历，遍历顺序与插入顺序一致。

#### 常用方法：

| 方法/属性         | 说明                                                  |
| ----------------- | ----------------------------------------------------- |
| `new Set()`       | 创建空Set（可传入数组初始化，如`new Set([1, 2, 3])`） |
| `set.add(val)`    | 添加元素（返回Set本身，支持链式调用）                 |
| `set.has(val)`    | 判断是否存在该元素（返回布尔值）                      |
| `set.delete(val)` | 删除指定元素（返回布尔值，表示是否删除成功）          |
| `set.clear()`     | 清空所有元素                                          |
| `set.size`        | 元素数量                                              |

#### 遍历方式：

```javascript
const set = new Set([1, 2, 3])

// 1. for...of 直接遍历元素
for (const val of set) {
  console.log(val) // 1、2、3
}

// 2. 遍历键（与值相同）
for (const key of set.keys()) {
  console.log(key) // 1、2、3
}

// 3. 遍历值
for (const val of set.values()) {
  console.log(val) // 1、2、3
}

// 4. forEach
set.forEach(val => {
  console.log(val)
})
```

#### 典型应用：

- 数组去重：`[...new Set(arr)]`
- 存储需要唯一标识的元素（如用户ID、标签等）。

### 三、WeakMap

`WeakMap`是**弱引用的键值对集合**，与`Map`类似，但限制更严格。

#### 核心特点：

- **键必须是对象**（不能是原始类型，如字符串、数字）。
- 键是**弱引用**：如果键对象没有其他引用，会被垃圾回收（GC），对应的键值对会自动从`WeakMap`中删除。
- 没有`size`属性，无法获取键值对数量。
- 不可遍历（没有`keys()`、`values()`等方法）。

#### 常用方法：

仅支持`get`、`set`、`has`、`delete`（无`clear`和`size`）：

```javascript
const wm = new WeakMap()
const obj = {}

// 设置键值对（键必须是对象）
wm.set(obj, '私有数据')

// 获取值
console.log(wm.get(obj)) // '私有数据'

// 判断存在
console.log(wm.has(obj)) // true

// 删除
wm.delete(obj)
```

#### 适用场景：

- 存储对象的临时/私有数据，且不希望影响对象的垃圾回收（如DOM元素的额外数据）。
- 避免内存泄漏（例如：给DOM元素绑定数据时，当DOM被删除，数据会自动清理）。

### 四、WeakSet

`WeakSet`是**弱引用的唯一值集合**，与`Set`类似，但限制更严格。

#### 核心特点：

- **值必须是对象**（不能是原始类型）。
- 值是**弱引用**：如果值对象没有其他引用，会被GC回收，自动从`WeakSet`中删除。
- 没有`size`属性，无法获取元素数量。
- 不可遍历（没有`keys()`、`values()`等方法）。

#### 常用方法：

仅支持`add`、`has`、`delete`（无`clear`和`size`）：

```javascript
const ws = new WeakSet()
const obj1 = {}
const obj2 = {}

// 添加元素（必须是对象）
ws.add(obj1).add(obj2)

// 判断存在
console.log(ws.has(obj1)) // true

// 删除
ws.delete(obj1)
```

#### 适用场景：

- 存储对象集合，且不希望影响对象的垃圾回收（如临时标记对象是否被处理过）。

### 对比总结

| 特性         | Map             | Set          | WeakMap            | WeakSet            |
| ------------ | --------------- | ------------ | ------------------ | ------------------ |
| 存储内容     | 键值对          | 唯一值       | 键值对（键是对象） | 唯一值（值是对象） |
| 键/值类型    | 键：任意类型    | 值：任意类型 | 键：必须是对象     | 值：必须是对象     |
| 引用类型     | 强引用          | 强引用       | 键是弱引用         | 值是弱引用         |
| 可遍历性     | 可遍历          | 可遍历       | 不可遍历           | 不可遍历           |
| size属性     | 有              | 有           | 无                 | 无                 |
| 垃圾回收影响 | 阻止键/值被回收 | 阻止值被回收 | 不影响键回收       | 不影响值回收       |

简单来说：

- 需要键值对且键类型灵活 → 用`Map`；
- 需要唯一值集合 → 用`Set`；
- 需要键值对且不希望影响键对象的回收 → 用`WeakMap`；
- 需要唯一对象集合且不希望影响对象回收 → 用`WeakSet`。

## 默认情况下，普通对象不能被`for...of`遍历？

默认情况下，普通对象（`{}`）确实不能被 `for...of` 遍历，核心原因是：**普通对象未默认部署“可迭代协议”（iterable protocol）**。

### 什么是“可迭代协议”？

`for...of` 循环的遍历逻辑依赖于“可迭代协议”—— 一个对象要能被 `for...of` 遍历，必须满足：

1. 该对象（或其原型链上）必须有一个名为 `Symbol.iterator` 的属性（这是一个特殊的内置 Symbol 值）。
2. `Symbol.iterator` 的值是一个**无参数函数**，调用后会返回一个符合“迭代器协议”的对象（即包含 `next()` 方法的对象）。

### 普通对象为什么不满足？

JavaScript 中，**普通对象（`Object`）的原型链上默认没有 `Symbol.iterator` 属性**，因此不满足“可迭代协议”，自然无法被 `for...of` 遍历。

尝试直接用 `for...of` 遍历普通对象会报错：

```javascript
const obj = { name: '张三', age: 20 }

// 报错：obj is not iterable
for (const item of obj) {
  console.log(item)
}
```

### 对比：为什么数组、Map 等可以被 `for...of` 遍历？

像数组（`Array`）、字符串（`String`）、`Map`、`Set`、`arguments` 等内置数据结构，**默认部署了 `Symbol.iterator` 属性**，因此是“可迭代对象”，可以直接被 `for...of` 遍历。

例如，数组的原型上有 `Symbol.iterator`：

```javascript
const arr = [1, 2, 3]
// 数组原型上存在 Symbol.iterator
console.log(Array.prototype[Symbol.iterator]) // 一个函数

// 因此可以被 for...of 遍历
for (const item of arr) {
  console.log(item) // 1、2、3（正常输出）
}
```

### 如何让普通对象可被 `for...of` 遍历？

如果需要让普通对象支持 `for...of` 遍历，**手动为其部署 `Symbol.iterator` 属性**即可，示例：

```javascript
const obj = {
  data: [10, 20, 30],
  // 手动部署 Symbol.iterator
  [Symbol.iterator]() {
    let index = 0
    // 返回一个迭代器（包含 next() 方法）
    return {
      next: () => {
        if (index < this.data.length) {
          // 未遍历完：返回当前值 + done: false
          return { value: this.data[index++], done: false }
        } else {
          // 遍历完：返回 done: true
          return { done: true }
        }
      }
    }
  }
}

// 现在可以用 for...of 遍历
for (const item of obj) {
  console.log(item) // 10、20、30（正常输出）
}
```

### 总结

普通对象默认不能被 `for...of` 遍历的根本原因是：  
**它未默认实现“可迭代协议”（缺少 `Symbol.iterator` 属性）**。

而 `for...of` 本质是通过调用对象的 `Symbol.iterator` 方法获取迭代器，再逐步遍历迭代器返回的值。只有实现了该协议的对象（如数组、`Map` 等），才能被 `for...of` 正常遍历。
