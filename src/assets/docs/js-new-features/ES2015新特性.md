# ES2015（es6）新特性

## 1. 块级作用域（let、const）：

let和const: 提供了更严谨的变量声明方式，let用于声明块级作用域变量，const用于声明常量。

```javascript
{
  let a = 10
  const b = 20
}
console.log(a) // 报错：a is not defined
console.log(b) // 报错：b is not defined
```

## 2. 箭头函数（Arrow Function）：

箭头函数是一种更简洁的函数表达式语法，它没有自己的this、arguments、super或new.target绑定，并且不能用作构造函数。

```javascript
const add = (a, b) => a + b
console.log(add(1, 2)) // 3
```

## 3. 对象字面量增强

### 1. 属性值缩写（Object Literal Property Value Shorthand）

属性值缩写是一种方便的对象字面量语法，它可以省略属性值和属性名相同的情况。

```javascript
const name = 'lily'
const age = 25
const obj = { name, age }
console.log(obj) // { name: 'lily', age: 25 }
```

### 2. 方法缩写（Object Literal Method Shorthand）

方法缩写是一种方便的对象字面量语法，它可以省略方法名和function关键字。

```javascript
const obj = {
  name: 'lily',
  age: 25,
  sayName() {
    console.log(this.name)
  }
}
obj.sayName() // lily
```

### 3. 计算属性名（Computed Property Names）

计算属性名是一种方便的对象字面量语法，它可以在对象字面量的定义阶段，直接使用方括号 [] 来包裹一个表达式，其计算结果将作为属性名。

```javascript
const name = 'name'
const age = 'age'
const obj = { [name]: 'lily', [age]: 25 }
console.log(obj) // { name: 'lily', age: 25 }
```

### 4. 在对象字面量设置原型

```javascript
const user = {
  name: 'lily',
  greet() {
    console.log(`hello ${this.name}!`)
  }
}
const admin = {
  __proto__: user, //  直接在这里设置原型！
  name: '管理员',
  role: 'admin'
}
console.log(admin.greet()) // hello 管理员!
console.log(admin.role) // admin
console.log(Object.getPrototypeOf(admin) === user) // true
```

### 5. 直接调用原型链上层（父层）的方法

在ES6中，我们可以使用 super 关键字来直接调用原型链上层（父层）的方法。

```javascript
class Animal {
  constructor(name) {
    this.name = name
  }
  sayName() {
    console.log(this.name)
  }
}
class Cat extends Animal {
  constructor(name) {
    super(name)
  }
  sayName() {
    super.sayName()
  }
}
const cat = new Cat('kitty')
cat.sayName() // kitty
```

或结合在对象字面量设置原型

```javascript
const user = {
  name: 'lily',
  greet() {
    console.log(`hello ${this.name}!`)
  }
}
const admin = {
  __proto__: user, //  直接在这里设置原型！
  name: '管理员',
  role: 'admin',
  greet() {
    const parentGreeting = super.greet()
    return `${parentGreeting} I have special permissions.`
  }
}
console.log(admin.greet()) // hello 管理员! I have special permissions.
```

## 4. for...of 循环

for...of循环是一种方便的遍历数组或类数组对象的方式，它可以直接获取数组或类数组对象的元素值，而不需要使用索引。

```javascript
const arr = [1, 2, 3]
for (const item of arr) {
  console.log(item)
}
// 1
// 2
// 3
```

## 5. 新增内置对象API

### object

#### 1. Object.assign()

Object.assign() 方法用于将所有可枚举属性的值从一个或多个源对象复制到目标对象。它返回目标对象。

```javascript
const target = { a: 1, b: 2 }
const source = { b: 4, c: 5 }
Object.assign(target, source)
console.log(target) // { a: 1, b: 4, c: 5 }
```

#### 2. Object.is()

Object.is() 方法用于判断两个值是否严格相等，它与严格比较运算符（===）的行为基本相同，但是它可以处理一些特殊情况，例如 NaN 和 -0。

1. +0 和 -0 被视为不相等。
2. NaN 和 NaN 被视为相等。

```javascript
console.log(Object.is(NaN, NaN)) // true
console.log(Object.is(-0, 0)) // false
```

#### 3. Object.keys()、Object.values()、Object.entries()

Object.keys()、Object.values()、Object.entries() 方法用于获取对象的键、值、键值对数组。

```javascript
const obj = { a: 1, b: 2, c: 3 }
console.log(Object.keys(obj)) // ['a', 'b', 'c']
console.log(Object.values(obj)) // [1, 2, 3]
console.log(Object.entries(obj)) // [['a', 1], ['b', 2], ['c', 3]]
```

#### 4. Object.getOwnPropertyDescriptors()

Object.getOwnPropertyDescriptors() 方法用于获取对象的所有属性描述符，包括不可枚举属性。

```javascript
const obj = { a: 1, b: 2 }
console.log(Object.getOwnPropertyDescriptors(obj))
// {
//   a: { value: 1, writable: true, enumerable: true, configurable: true },
//   b: { value: 2, writable: true, enumerable: true, configurable: true }
// }
```

#### 5. Object.getOwnPropertySymbols()

Object.getOwnPropertySymbols() 方法用于获取对象的所有 Symbol 属性名。

```javascript
const obj = { a: 1, b: 2 }
const sym = Symbol('sym')
obj[sym] = 3
console.log(Object.getOwnPropertySymbols(obj)) // [Symbol(sym)]
```

#### 6. Object.setPrototypeOf()和Object.getPrototypeOf()

- Object.setPrototypeOf() 方法用于设置对象的原型（即内部 [[Prototype]] 属性）。

- Object.getPrototypeOf() 方法用于获取对象的原型（即内部 [[Prototype]] 属性）。

**用途**：在对象创建后动态地改变或读取其原型链，它们是官方推荐的、用于操作原型的标准方法。

```javascript
const obj = { a: 1, b: 2 }
const proto = { c: 3 }
Object.setPrototypeOf(obj, proto)
console.log(obj.__proto__) // { c: 3 }
console.log(Object.getPrototypeOf(obj)) // { c: 3 }
```

### Array

#### 1. Array.from()

Array.from() 方法用于将类数组对象或可迭代对象转换为数组。

```javascript
const str = 'hello'
const arr = Array.from(str)
console.log(arr) // ['h', 'e', 'l', 'l', 'o']
```

#### 2. Array.of()

Array.of() 方法用于创建一个具有可变数量参数的新数组实例，而不考虑参数的数量或类型。它解决了 `new Array()` 的歧义问题。`Array.of(7)` 创建一个具有单个元素 7 的数组，而 `Array(7)` 创建一个 length 为 7 的空数组（这意味着一个由 7 个空槽组成的数组，而不是由 7 个 undefined 组成的数组）。

```javascript
const arr = Array.of(1, 2, 3)
console.log(arr) // [1, 2, 3]
```

#### 3. Array.prototype.includes()

Array.prototype.includes() 方法用于判断数组是否包含指定元素，返回一个布尔值。

```javascript
const arr = [1, 2, 3]
console.log(arr.includes(2)) // true
console.log(arr.includes(4)) // false
```

#### 4. Array.prototype.find()和Array.prototype.findIndex()

Array.prototype.find() 方法用于查找数组中满足指定条件的第一个元素，并返回该元素。如果没有符合条件的元素，则返回 undefined。

Array.prototype.findIndex() 方法用于查找数组中满足指定条件的第一个元素的索引，并返回该索引。如果没有符合条件的元素，则返回 -1。

```javascript
const arr = [1, 2, 3, 4, 5]
console.log(arr.find(item => item > 3)) // 4
console.log(arr.findIndex(item => item > 3)) // 3
```

#### 5. Array.prototype.fill()

Array.prototype.fill() 方法用于将数组的所有元素填充为指定值。

```javascript
const arr = [1, 2, 3, 4, 5]
arr.fill(0)
console.log(arr) // [0, 0, 0, 0, 0]
```

#### 6. Array.prototype.copyWithin()

Array.prototype.copyWithin() 方法用于在数组内部浅复制元素，它可以将数组的一部分元素复制到另一个位置，并返回它，不会改变原数组的长度。

Array.prototype.copyWithin() 方法的语法如下：

```javascript
arr.copyWithin(target, start, end)
```

- target：要复制到的目标位置索引。
- start：要复制的起始位置索引（包含）。
- end：要复制的结束位置索引（不包含）。如果未指定，则默认复制到数组末尾。

```javascript
const arr = [1, 2, 3, 4, 5]
arr.copyWithin(0, 3, 4)
console.log(arr) // [4, 2, 3, 4, 5]
```

#### 7. Array.prototype.entries()

Array.prototype.entries() 方法用于返回数组的键值对迭代器。

```javascript
const arr = [1, 2, 3]
const iterator = arr.entries()
console.log(iterator.next().value) // [0, 1]
console.log(iterator.next().value) // [1, 2]
console.log(iterator.next().value) // [2, 3]
```

#### 8. Array.prototype.keys()

Array.prototype.keys() 方法用于返回数组的键迭代器。

```javascript
const arr = [1, 2, 3]
const iterator = arr.keys()
console.log(iterator.next().value) // 0
console.log(iterator.next().value) // 1
console.log(iterator.next().value) // 2
```

#### 9. Array.prototype.values()

Array.prototype.values() 方法用于返回数组的值迭代器。

```javascript
const arr = [1, 2, 3]
const iterator = arr.values()
console.log(iterator.next().value) // 1
console.log(iterator.next().value) // 2
console.log(iterator.next().value) // 3
```

## 8. 扩展运算符（Spread Operator）：

## 9. 函数参数扩展

### 1. 默认参数值（Default Parameter Values）：

默认参数值是一种方便的函数参数赋值方式，它可以在函数调用时省略参数，使用默认值。

```javascript
const add = (a = 0, b = 0) => a + b
console.log(add(1, 2)) // 3
console.log(add(1)) // 1
console.log(add()) // 0
```

### 2. 剩余/不定参数（Rest Parameters）：

在ES6之前的规范中我们大可以使用arguments变量来达到不定参数的判断。
ES6的剩余参数（又称不定参数）使用三个点 (...) 来表示，它允许函数接收不定数量的参数，并将这些参数收集到一个数组中。 不定参数必须是最后一个参数，并且一个函数中只能有一个不定参数。

```javascript
const add = (...args) => args.reduce((a, b) => a + b, 0)
console.log(add(1, 2, 3)) // 6
console.log(add(1, 2, 3, 4)) // 10
```

### 3. 拓展参数

关于拓展参数，其实拓展参数其实一种语法糖，它允许传递一个数组（或者类数组）作为函数的参数，而不需要apply操作，函数内部可以自动将其当前不定参数解析，然后可以获得每一个数组（类数组）元素作为实际参数。

```javascript
function foo(x, y, z) {
  return x + y + z
}
console.log(foo(...[1, 2, 3])) // 6
```

## 10. 类

类是一种方便的对象创建方式，它可以定义对象的属性和方法。

```javascript
class Person {
  constructor(name, age) {
    this.name = name
    this.age = age
  }
  say() {
    console.log(`My name is ${this.name}, and I am ${this.age} years old.`)
  }

const p = new Person('lily', 25)
p.say() // My name is lily, and I am 25 years old.
```

## 11. 模块化（Modules）：

模块化是一种方便的代码组织方式，它可以将代码分成多个模块，每个模块都有自己的作用域，并且可以导出和导入其他模块的代码。
使用`import`和`export`进行模块化管理。

```javascript
// math.js
export const add = (a, b) => a + b

// app.js
import { add } from './math.js'
console.log(add(1, 2)) // 3
```

## 12. Promise

Promise是一种方便的异步编程方式，它可以处理异步操作的结果，避免回调地狱。

```javascript
const p = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('success')
  }, 1000)
})
p.then(res => console.log(res)) // success
```

## 13. 迭代器（Iterators）和生成器（Generators）：

- 迭代器是一种方便的遍历方式，它可以遍历数组、字符串、Set、Map等数据结构。
- 生成器是一种方便的异步编程方式，它可以暂停和恢复执行，并且可以返回多个值。

```javascript
const arr = [1, 2, 3]
const iter = arr[Symbol.iterator]()
console.log(iter.next()) // { value: 1, done: false }
console.log(iter.next()) // { value: 2, done: false }
console.log(iter.next()) // { value: 3, done: false }
console.log(iter.next()) // { value: undefined, done: true }
```

## 14. 代理（Proxy）和反射（Reflection）：

- 代理是一种方便的对象创建方式，它可以拦截和修改对象的默认行为。
- 反射是一种方便的对象操作方式，它可以在运行时动态地调用对象的方法和属性。

```javascript
const obj = { name: 'lily', age: 25 }
const proxy = new Proxy(obj, {
  get(target, prop) {
    console.log(`get ${prop}`)
    return Reflect.get(target, prop)
  },
  set(target, prop, value) {
    console.log(`set ${prop} to ${value}`)
    return Reflect.set(target, prop, value)
  }
})
console.log(proxy.name) // get name, lily
console.log(proxy.age) // get age, 25
proxy.sex = 'male' // set sex to male
console.log(proxy.sex) // get sex, male
```

## 15. Symbol

在 **JavaScript** 中，`Symbol` 是 ES6 引入的第六种原始数据类型（其余五种为：`Number`、`String`、`Boolean`、`Null`、`Undefined`）（js还包含了`Object`引用数据类型），用于表示独一无二的值。它的核心特点是 “唯一性”，这使得它在解决命名冲突、创建私有属性等场景中非常有用。

### 一、基本概念与创建方式

`Symbol` 通过全局的 `Symbol()` 函数创建，**不能使用 `new` 关键字**（因为它是原始类型，不是对象）。

```javascript
// 创建一个Symbol
const s1 = Symbol()
console.log(typeof s1)
// symbol（注意：小写，区分于Object等）

// 可以传入一个字符串作为"描述"（仅用于调试，不影响Symbol的唯一性）
const s2 = Symbol('description')
console.log(s2.toString())
// Symbol(description)
```

**关键特性**：即使描述相同，两个Symbol也不相等（唯一性）。

```javascript
const s3 = Symbol('foo')
const s4 = Symbol('foo')
console.log(s3 === s4)
// false
```

### 二、核心特性

#### 1. 唯一性

这是`Symbol`最核心的特性：**任何两个通过`Symbol()`创建的值都是独一无二的**，无论描述是否相同。  
这解决了传统字符串作为键时可能出现的命名冲突问题（例如不同模块给同一对象添加属性时）。

#### 2. 不可枚举性

当`Symbol`作为对象的属性键时，默认**不会被枚举**（即不会出现在`for...in`、`Object.keys()`、`Object.getOwnPropertyNames()` 或 `JSON.stringify()` 的结果中）。这个特性使得 Symbol 非常适合用来定义对象的内部或元数据属性。

```javascript
const obj = {
  [s3]: 'value', // 用Symbol作为属性键（需用方括号）
  name: '张三'
}

// 遍历对象属性
for (const key in obj) {
  console.log(key) // 仅输出 name（Symbol键不会被遍历到）
}

console.log(JSON.stringify(obj)) // {"name":"张三"}（Symbol键被忽略）
console.log(Object.keys(obj)) // ['name']（同样不包含Symbol键）
console.log(Object.getOwnPropertyNames(obj)) // ['name']（同样不包含Symbol键）
```

如果需要获取对象的Symbol属性，需使用专门的方法`Object.getOwnPropertySymbols()`、`Reflect.ownKeys()`：

```javascript
console.log(Object.getOwnPropertySymbols(obj)) // [Symbol(foo)]（返回所有Symbol键）
console.log(Reflect.ownKeys(obj)) // ['name', Symbol(foo)]（包含所有键，包括Symbol）
```

#### 3. 可作为对象键/属性名

`Symbol`可以作为对象的属性键，包括对象字面量（需用方括号包裹）和类的属性。

```javascript
// 1. 对象字面量中使用
const s5 = Symbol('id')
const user = {
  [s5]: 1001 // 必须用方括号，否则会被当作字符串
}

// 2. 类中使用
class MyClass {
  [Symbol('method')]() {
    return '这是一个Symbol方法'
  }
}
const instance = new MyClass()
console.log(instance[Symbol('method')]) // undefined（注意：这里的Symbol是新创建的，与类中不同）
```

> 注意：访问Symbol属性时，必须使用**同一个Symbol值**（因为Symbol是唯一的）。

#### 4. 不能与其他类型直接运算

`Symbol`不能与字符串、数字等类型进行算术或字符串拼接运算，会报错：

```javascript
const s6 = Symbol('num')
// console.log(s6 + 1); // 报错：Cannot convert a Symbol value to a number
// console.log('symbol: ' + s6); // 报错：Cannot convert a Symbol value to a string
```

但可以通过`toString()`方法转为字符串后再运算：

```javascript
console.log('symbol: ' + s6.toString()) // "symbol: Symbol(num)"
```

#### 5. 转换为布尔值时恒为`true`

`Symbol`转换为布尔值时永远是`true`（不存在“ false ”的Symbol）：

```javascript
console.log(Boolean(Symbol())) // true
if (Symbol()) {
  console.log('执行') // 会执行
}
```

#### 6. 全局共享的 Symbol：Symbol.for() 和 Symbol.keyFor()

虽然 Symbol() 总是创建唯一的 Symbol，但有时我们可能需要在不同的代码文件或作用域中共享同一个 Symbol。为此，ES6 提供了全局 Symbol 注册表。

- `Symbol.for(key)`：根据键名（字符串）创建或获取全局 Symbol。如果键名不存在，则创建新的 Symbol；如果已存在，则返回已存在的 Symbol。
- `Symbol.keyFor(symbol)`：根据全局 Symbol 获取其对应的键名（字符串）。如果 Symbol 不是全局 Symbol，则返回 `undefined`。

```javascript
// 创建一个全局Symbol（如果不存在则创建，否则返回已存在的Symbol）
const s7 = Symbol.for('globalSymbol')
console.log(s7) // Symbol(globalSymbol)

// 获取全局Symbol的描述（如果不存在则返回undefined）
console.log(Symbol.keyFor(s7)) // "globalSymbol"
```

### 三、内置Symbol值（Well-known Symbols）

ES6 还提供了一系列内置的、全局可用的 "Well-Known Symbols"。这些 Symbol 作为 Symbol 对象的静态属性存在，例如 `Symbol.iterator`、`Symbol.toPrimitive` 等。 它们允许开发者通过在自己的对象上定义这些 Symbol 属性，来“钩入”并自定义 JavaScript 语言的内部行为

常见的内置Symbol：

| 内置Symbol           | 作用                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `Symbol.iterator`    | 定义对象的默认迭代器（使对象可被`for...of`遍历）                   |
| `Symbol.toStringTag` | 自定义对象的`toString()`返回值（如`[object Array]`中的`Array`）    |
| `Symbol.hasInstance` | 定义`instanceof`运算符的行为（如`obj instanceof Class`的判断逻辑） |
| `Symbol.species`     | 定义衍生对象的构造函数（如数组切片返回新数组时的构造函数）         |
| `Symbol.toPrimitive` | 定义对象转换为原始值的逻辑（如`obj + 1`时的转换规则）              |

#### 示例：使用`Symbol.iterator`使对象可迭代

<font color='blue'>默认情况下，普通对象不能被`for...of`遍历（有疑问，解释在后面）</font>，但可以通过`Symbol.iterator`定义迭代器：

```javascript
const iterableObj = {
  data: [1, 2, 3],
  // 定义迭代器
  [Symbol.iterator]() {
    let index = 0
    return {
      next: () => {
        if (index < this.data.length) {
          return { value: this.data[index++], done: false }
        } else {
          return { done: true }
        }
      }
    }
  }
}

// 现在可以用for...of遍历
for (const item of iterableObj) {
  console.log(item) // 1、2、3
}
```

#### 示例：用`Symbol.toStringTag`自定义`toString()`结果

默认情况下，对象的`toString()`返回`"[object Object]"`，可通过`Symbol.toStringTag`修改：

```javascript
const myObj = {
  [Symbol.toStringTag]: 'MyCustomObject'
}
console.log(myObj.toString()) // [object MyCustomObject]
```

### 四、应用场景

#### 1. 避免对象属性名冲突

当多个模块需要给同一个对象添加属性时，用`Symbol`作为键可以避免命名冲突（因为Symbol是唯一的）。

```javascript
// 模块A
const moduleAKey = Symbol('id')
obj[moduleAKey] = 'A模块的数据'

// 模块B
const moduleBKey = Symbol('id') // 即使描述相同，也是不同的Symbol
obj[moduleBKey] = 'B模块的数据' // 不会覆盖模块A的数据
```

#### 2. 创建“私有”属性

虽然JavaScript没有真正的私有属性，但`Symbol`属性默认不可枚举，且需要通过具体的Symbol值才能访问，可模拟私有属性（避免被意外修改）。

```javascript
const privateKey = Symbol('private')

class User {
  constructor(name) {
    this.name = name
    this[privateKey] = '私有信息' // 模拟私有属性
  }

  getPrivate() {
    return this[privateKey] // 只能通过类的方法访问
  }
}

const user = new User('张三')
console.log(user[privateKey]) // 能访问到（并非真正私有），但不容易被意外操作
console.log(user.getPrivate()) // "私有信息"
```

#### 3. 定义对象的特殊行为

通过内置Symbol（如`Symbol.iterator`、`Symbol.toPrimitive`）自定义对象的默认行为，实现更灵活的逻辑。

### 总结

`Symbol`的核心是“唯一性”，主要用于：

- 解决属性名冲突；
- 模拟私有属性；
- 自定义对象的内置行为（通过内置Symbol）。

它的不可枚举性和唯一性，让它在复杂场景中（如多模块协作、框架开发）非常实用。

## 16. 新增数据结构：

`Map`、`Set`、`WeakMap`、`WeakSet`是新引入的四种集合类型数据结构，它们在存储数据和使用场景上各有特点。下面分别详解：

### 一、Map

`Map`是**键值对的集合**，类似对象，但键的类型更灵活（可任意类型）。

#### 核心特点：

- 键可以是任意类型（字符串、数字、对象、函数等），而普通对象的键只能是字符串或`Symbol`。
- 键是唯一的（重复设置会覆盖）。
- 有明确的大小（`size`属性），可直接获取键值对数量。
- 可遍历（支持`for...of`、`forEach`等），遍历顺序与插入顺序一致。

#### 常用方法：

| 方法/属性           | 说明                                                                         |
| ------------------- | ---------------------------------------------------------------------------- |
| `new Map()`         | 创建空Map（可传入二维数组初始化，如`new Map([[key1, val1], [key2, val2]])`） |
| `map.set(key, val)` | 添加/修改键值对（返回Map本身，支持链式调用）                                 |
| `map.get(key)`      | 获取键对应的值（不存在返回`undefined`）                                      |
| `map.has(key)`      | 判断是否存在该键（返回布尔值）                                               |
| `map.delete(key)`   | 删除指定键（返回布尔值，表示是否删除成功）                                   |
| `map.clear()`       | 清空所有键值对                                                               |
| `map.size`          | 键值对数量                                                                   |

#### 遍历方式：

```javascript
const map = new Map([
  ['name', '张三'],
  ['age', 20]
])

// 1. 遍历键
for (const key of map.keys()) {
  console.log(key) // 'name'、'age'
}

// 2. 遍历值
for (const val of map.values()) {
  console.log(val) // '张三'、20
}

// 3. 遍历键值对（默认）
for (const [key, val] of map) {
  console.log(key, val) // 'name' '张三'、'age' 20
}

// 4. forEach
map.forEach((val, key) => {
  console.log(key, val)
})
```

#### 适用场景：

- 需要非字符串类型作为键（如用对象做键）。
- 需要频繁增删键值对并关注数量（`size`属性）。
- 需要保持插入顺序并遍历。

### 二、Set

`Set`是**唯一值的集合**（无重复值），类似数组，但元素不可重复。

#### 核心特点：

- 元素唯一（重复添加会被忽略）。
- 元素可以是任意类型。
- 有明确的大小（`size`属性）。
- 可遍历，遍历顺序与插入顺序一致。

#### 常用方法：

| 方法/属性         | 说明                                                  |
| ----------------- | ----------------------------------------------------- |
| `new Set()`       | 创建空Set（可传入数组初始化，如`new Set([1, 2, 3])`） |
| `set.add(val)`    | 添加元素（返回Set本身，支持链式调用）                 |
| `set.has(val)`    | 判断是否存在该元素（返回布尔值）                      |
| `set.delete(val)` | 删除指定元素（返回布尔值，表示是否删除成功）          |
| `set.clear()`     | 清空所有元素                                          |
| `set.size`        | 元素数量                                              |

#### 遍历方式：

```javascript
const set = new Set([1, 2, 3])

// 1. for...of 直接遍历元素
for (const val of set) {
  console.log(val) // 1、2、3
}

// 2. 遍历键（与值相同）
for (const key of set.keys()) {
  console.log(key) // 1、2、3
}

// 3. 遍历值
for (const val of set.values()) {
  console.log(val) // 1、2、3
}

// 4. forEach
set.forEach(val => {
  console.log(val)
})
```

#### 典型应用：

- 数组去重：`[...new Set(arr)]`
- 存储需要唯一标识的元素（如用户ID、标签等）。

### 三、WeakMap

`WeakMap`是**弱引用的键值对集合**，与`Map`类似，但限制更严格。

#### 核心特点：

- **键必须是对象**（不能是原始类型，如字符串、数字）。
- 键是**弱引用**：如果键对象没有其他引用，会被垃圾回收（GC），对应的键值对会自动从`WeakMap`中删除。
- 没有`size`属性，无法获取键值对数量。
- 不可遍历（没有`keys()`、`values()`等方法）。

#### 常用方法：

仅支持`get`、`set`、`has`、`delete`（无`clear`和`size`）：

```javascript
const wm = new WeakMap()
const obj = {}

// 设置键值对（键必须是对象）
wm.set(obj, '私有数据')

// 获取值
console.log(wm.get(obj)) // '私有数据'

// 判断存在
console.log(wm.has(obj)) // true

// 删除
wm.delete(obj)
```

#### 适用场景：

- 存储对象的临时/私有数据，且不希望影响对象的垃圾回收（如DOM元素的额外数据）。
- 避免内存泄漏（例如：给DOM元素绑定数据时，当DOM被删除，数据会自动清理）。

### 四、WeakSet

`WeakSet`是**弱引用的唯一值集合**，与`Set`类似，但限制更严格。

#### 核心特点：

- **值必须是对象**（不能是原始类型）。
- 值是**弱引用**：如果值对象没有其他引用，会被GC回收，自动从`WeakSet`中删除。
- 没有`size`属性，无法获取元素数量。
- 不可遍历（没有`keys()`、`values()`等方法）。

#### 常用方法：

仅支持`add`、`has`、`delete`（无`clear`和`size`）：

```javascript
const ws = new WeakSet()
const obj1 = {}
const obj2 = {}

// 添加元素（必须是对象）
ws.add(obj1).add(obj2)

// 判断存在
console.log(ws.has(obj1)) // true

// 删除
ws.delete(obj1)
```

#### 适用场景：

- 存储对象集合，且不希望影响对象的垃圾回收（如临时标记对象是否被处理过）。

### 对比总结

| 特性         | Map             | Set          | WeakMap            | WeakSet            |
| ------------ | --------------- | ------------ | ------------------ | ------------------ |
| 存储内容     | 键值对          | 唯一值       | 键值对（键是对象） | 唯一值（值是对象） |
| 键/值类型    | 键：任意类型    | 值：任意类型 | 键：必须是对象     | 值：必须是对象     |
| 引用类型     | 强引用          | 强引用       | 键是弱引用         | 值是弱引用         |
| 可遍历性     | 可遍历          | 可遍历       | 不可遍历           | 不可遍历           |
| size属性     | 有              | 有           | 无                 | 无                 |
| 垃圾回收影响 | 阻止键/值被回收 | 阻止值被回收 | 不影响键回收       | 不影响值回收       |

简单来说：

- 需要键值对且键类型灵活 → 用`Map`；
- 需要唯一值集合 → 用`Set`；
- 需要键值对且不希望影响键对象的回收 → 用`WeakMap`；
- 需要唯一对象集合且不希望影响对象回收 → 用`WeakSet`。

## 17. Unicode的支持

**ES6** 加强了对Unicode 的支持，引入了 `\u{...}` 语法来表示码点，解决了旧的 `\uxxxx` 语法只能处理码点在 \(0000\) 到 \(FFFF\) 之间的Unicode 字符的问题。 这意味着ES6 可以正确地处理超出基本多文种平面(BMP) 的字符，例如一些Emoji 表情符号，从而更准确地支持完整的Unicode 字符集。

```javascript
/**
 * 旧的Unicode 转义表示法
 * \xXX:XX 必须是介于 00 与 FF 之间的2位十六进制数,所以它只能用于前 256 个 Unicode 字符。
 * \uXX:XX 必须是介于 0000 与 FFFF 之间的4位十六进制数。
 */

console.log('\xA9') // ©
console.log('\u00A9') // ©
// 新的Unicode 转义表示法
console.log('\u{A9}') // ©
console.log('\u{1F600}') // 😀
console.log('\u{1F600}'.length) // 2
console.log('\u{1F600}'.codePointAt(0)) // 128512
// for...of 循环，下面代理对部分内容有讲解
/**
 * 代理对（Surrogate Pair）
 * 代理对是一种用于表示超出基本多文种平面（BMP）的 Unicode 字符的编码方式。
 * 它由两个 16 位的 Unicode 码点组成，第一个码点（称为高代理项）在 \(D800-DFFF\) 范围内，第二个码点（称为低代理项）在 \(DC00-DFFF\) 范围内。
 * 代理对的作用是将一个 32 位的 Unicode 码点表示为两个 16 位的码点，从而在 UTF-16 编码中表示超出 BMP 的字符。
 */
const text = '你好𠮷'
for (const char of text) {
  console.log(`字符: ${char}`)
}
// 字符: 你
// 字符: 好
// 字符: 𠮷
```

### 主要改进：

- **新的Unicode 转义表示法**： 引入了 `{}` 包裹的码点表示法，例如 `\u{1F600}`，可以表示任何Unicode 字符的码点，**解决了旧的 `\uxxxx` 只能处理 \(0000-FFFF\) 范围**的问题。 
- **更好的字符串处理**：在**ES6** 之前，JavaScript 的字符串是基于16 位字符编码（UTF-16）的，像 `length` 和 `charAt()` 这些方法会错误地处理超出**BMP** 的字符。 **ES6** 的改进使得这些方法能更准确地处理整个Unicode 字符集。
- **`for...of` 循环的支持**： **ES6** 的 `for...of` 循环可以正确地遍历字符串中的Unicode 字符，包括一些由两个代理对组成的字符，这与旧的 `for` 循环不同。

# 补充说明

## 1. 默认情况下，普通对象不能被`for...of`遍历？

默认情况下，普通对象（`{}`）确实不能被 `for...of` 遍历，核心原因是：**普通对象未默认部署“可迭代协议”（iterable protocol）**。

### 什么是“可迭代协议”？

`for...of` 循环的遍历逻辑依赖于“可迭代协议”—— 一个对象要能被 `for...of` 遍历，必须满足：

1. 该对象（或其原型链上）必须有一个名为 `Symbol.iterator` 的属性（这是一个特殊的内置 Symbol 值）。
2. `Symbol.iterator` 的值是一个**无参数函数**，调用后会返回一个符合“迭代器协议”的对象（即包含 `next()` 方法的对象）。

### 普通对象为什么不满足？

JavaScript 中，**普通对象（`Object`）的原型链上默认没有 `Symbol.iterator` 属性**，因此不满足“可迭代协议”，自然无法被 `for...of` 遍历。

尝试直接用 `for...of` 遍历普通对象会报错：

```javascript
const obj = { name: '张三', age: 20 }

// 报错：obj is not iterable
for (const item of obj) {
  console.log(item)
}
```

### 对比：为什么数组、Map 等可以被 `for...of` 遍历？

像数组（`Array`）、字符串（`String`）、`Map`、`Set`、`arguments` 等内置数据结构，**默认部署了 `Symbol.iterator` 属性**，因此是“可迭代对象”，可以直接被 `for...of` 遍历。

例如，数组的原型上有 `Symbol.iterator`：

```javascript
const arr = [1, 2, 3]
// 数组原型上存在 Symbol.iterator
console.log(Array.prototype[Symbol.iterator]) // 一个函数

// 因此可以被 for...of 遍历
for (const item of arr) {
  console.log(item) // 1、2、3（正常输出）
}
```

### 如何让普通对象可被 `for...of` 遍历？

如果需要让普通对象支持 `for...of` 遍历，**手动为其部署 `Symbol.iterator` 属性**即可，示例：

```javascript
const obj = {
  data: [10, 20, 30],
  // 手动部署 Symbol.iterator
  [Symbol.iterator]() {
    let index = 0
    // 返回一个迭代器（包含 next() 方法）
    return {
      next: () => {
        if (index < this.data.length) {
          // 未遍历完：返回当前值 + done: false
          return { value: this.data[index++], done: false }
        } else {
          // 遍历完：返回 done: true
          return { done: true }
        }
      }
    }
  }
}

// 现在可以用 for...of 遍历
for (const item of obj) {
  console.log(item) // 10、20、30（正常输出）
}
```

### 总结

普通对象默认不能被 `for...of` 遍历的根本原因是：  
**它未默认实现“可迭代协议”（缺少 `Symbol.iterator` 属性）**。

而 `for...of` 本质是通过调用对象的 `Symbol.iterator` 方法获取迭代器，再逐步遍历迭代器返回的值。只有实现了该协议的对象（如数组、`Map` 等），才能被 `for...of` 正常遍历。

## 2. Unicode是什么？

Unicode，又称统一码、万国码，是信息技术领域的一项业界标准。它为世界上绝大多数的文字系统进行了整理、编码，使得计算机可以用统一的字符集来处理和显示文本，解决了跨语言、跨平台进行文本转换与处理的难题。

### **Unicode 的起源：告别乱码时代**

在Unicode出现之前，世界各地的计算机系统使用着许多不同的编码方案。 例如，美国信息交换标准代码（ASCII）是早期为英文字符设计的编码，它使用7位二进制数表示128个字符。 随着计算机在全球的普及，各个国家和地区都制定了自己的编码标准以支持本地语言，例如中国的GB2312和GBK，台湾的BIG5，以及西欧语言的ISO/IEC 8859系列等。

这些不同的编码方式带来了严重的问题：

- **兼容性差**：在一种编码系统下创建的文档，在另一种系统下打开时常常会显示为无意义的乱码。
- **多语言混合困难**：传统的编码方式通常只允许处理双语环境（例如拉丁字母和本地语言），但无法在同一份文档中同时支持多种语言。
- **编码空间有限**：许多传统编码方案的容量不足以容纳世界上所有的字符。

为了解决这些混乱的状况，统一所有字符编码的设想应运而生。 Unicode项目始于1987年，**旨在创建一个能容纳世界上所有文字和符号的通用字符集**。

### **Unicode 的工作原理**

Unicode的核心思想是<font color="red">**为每个字符分配一个唯一的数字，这个数字被称为“码点”（Code Point）。 <u>码点通常用“U+”加上十六进制的数字来表示**</u></font>，例如，小写字母“a”的码点是U+0061。 这种设计将字符本身与其二进制表示分离开来。

**1. 字符集与码点**
Unicode标准定义了一个巨大的字符集，截至2025年9月公布的17.0.0版本，已收录超过15万个字符。 它不仅包括了现代世界的所有语言文字，还包含了符号、表情符号（Emoji）甚至古代的文字（如埃及象形文字）。

为了有效地组织这些海量的字符，<font color="red">**Unicode将整个编码空间分成了17个“平面”（Plane），每个平面包含65,536（2<sup>16</sup>）个码点。 第0平面被称为“基本多文种平面”（Basic Multilingual Plane, BMP），包含了最常用的大部分字符**</font>。

**2. 编码方式 (UTF)**
有了统一的码点，还需要一套规则将其转换为计算机可以存储和传输的二进制序列，这就是“统一码转换格式”（Unicode Transformation Format, UTF）。 常见的UTF编码方式有：

- **UTF-8**：这是一种可变长度的编码方式，它使用1到4个字节来表示一个字符。
  - **优点**：它完全兼容ASCII码，对于英文字符只使用1个字节存储，与ASCII相同，因此在以英文为主的文本中非常节省空间，在互联网上应用最为广泛。
  - **原理**：对于单字节字符，首位设为0；对于多字节字符，第一个字节的前几位设为1，用于表示编码所需的字节数，后续字节则以“10”开头。

- **UTF-16**：这也是一种可变长度的编码方式，它使用2个或4个字节来表示一个字符。
  - **优点**：对于基本多文种平面（BMP）中的常用字符（包括大多数常用汉字），UTF-16使用固定的2个字节表示，处理速度较快。
  - **缺点**：与ASCII不兼容，且存在字节序（大端序或小端序）的问题。

- **UTF-32**：这是一种固定长度的编码方式，任何字符都使用4个字节来表示。
  - **优点**：处理简单，因为每个字符长度固定。
  - **缺点**：占用存储空间较大，是UTF-8的数倍。

### **Unicode 的优势**

- **统一标准**：提供了一个全球通用的字符编码标准，让文本在不同的平台、操作系统和编程语言中都能被准确地表示和解释。
- **支持多语言**：能够在一个文档中混合使用多种语言的文本，无需复杂的转换，为软件的国际化和本地化提供了便利。
- **全面性**：其目标是涵盖人类语言使用的所有字符，包括现代语言、古文字、符号和表情符号等。
- **可扩展性**：Unicode标准仍在不断增修，定期纳入新的字符以满足用户需求。

总而言之，Unicode的出现是计算机发展史上的一座里程碑。它通过提供一个统一、全面的字符编码方案，极大地促进了全球信息的无障碍交流，成为现代软件和互联网技术不可或缺的基础。

## 3. 代理对（Surrogate Pairs）

在 JavaScript 中，字符串在内存中是以 UTF-16 编码存储的。对于 Unicode 中码点在 `U+0000` 到 `U+FFFF` 之间的字符（基本多文种平面，BMP），UTF-16 使用一个 16 位的编码单元（即两个字节）来表示，这与 JavaScript 字符串的单个字符长度 `1` 是对应的。

然而，对于超出这个范围的字符，例如很多表情符号（Emoji）或者一些不常用的汉字，其码点更大。UTF-16 会使用两个 16 位的编码单元（即四个字节）来表示一个字符，这两个单元就称为“代理对”。

代理对的组成：

- **高位代理项（High Surrogate）**：第一个16位的代码单元，范围在 `U+D800` 到 `U+DBFF` 之间的码点。
- **低位代理项（Low Surrogate）**：第二个16位的代码单元，范围在 `U+DC00` 到 `U+DFFF` 之间的码点。

这两个代码单元组合在一起，就形成了一个代理对，共同表示一个补充字符。但是这导致了一个问题：在早期的 JavaScript（ES6 之前）中，字符串的 `length` 属性和通过索引（`str[i]`）访问字符时，会将代理对的每个部分都当成一个独立的“字符”，从而导致错误的处理。

### 代码示例

我们以汉字“𠮷”（jí）为例，它的 Unicode 码点是 `U+20BB7`，超出了 BMP 的范围，因此需要用代理对来表示。

```javascript
// 这是一个由代理对组成的 Unicode 字符
const character = '𠮷'
```

#### 1. 错误的遍历方式：传统的 `for` 循环

传统的 `for` 循环是基于字符串的 `length` 属性和索引来工作的。它会将“𠮷”这个字符误认为是两个独立的单元。

```javascript
const text = '你好𠮷'

console.log(`字符串的 length 属性值: ${text.length}`)
console.log('--- 使用传统的 for 循环 ---')

for (let i = 0; i < text.length; i++) {
  console.log(`索引 ${i}: ${text[i]}`)
}
```

**运行结果：**

```
字符串的 length 属性值: 4
--- 使用传统的 for 循环 ---
索引 0: 你
索引 1: 好
索引 2: �
索引 3: �
```

**结果分析：**

- `text.length` 的值是 `4` 而不是 `2`，因为它把“𠮷”计算成了两个编码单元的长度。
- 循环输出了四个“字符”。前两个“你”和“好”是正确的。
- 当循环到索引 `2` 时，`text[2]` 访问到的只是“𠮷”这个代理对的前半部分，它本身无法构成一个有效的字符，因此被显示为一个无效字符（通常是问号或方块 `�`）。传统的 `for` 循环彻底“肢解”了这个字符。

#### 2. 正确的遍历方式：ES6 `for...of` 循环

ES6 引入的 `for...of` 循环是为遍历可迭代对象（Iterable）而设计的，字符串就是一种可迭代对象。它的迭代器（Iterator）能够正确识别 Unicode 代理对，并将它们作为一个完整的字符来处理。

```javascript
const text = '你好𠮷'

console.log(`字符串的 length 属性值: ${text.length}`)
console.log('--- 使用 ES6 的 for...of 循环 ---')

for (const char of text) {
  console.log(`字符: ${char}`)
}
```

**运行结果：**

```
字符串的 length 属性值: 3
--- 使用 ES6 的 for...of 循环 ---
字符: 你
字符: 好
字符: 𠮷
```

**结果分析：**

- `for...of` 循环并没有被 `text.length` 的值所迷惑。
- 它正确地迭代了两次，输出了两个我们肉眼可见的字符。
- 复杂的汉字“𠮷”被作为一个完整的、单一的字符正确地输出了。

### 总结

| 特性           | 传统 `for` 循环 (`for (let i=0;...)`)      | ES6 `for...of` 循环                                        |
| :------------- | :----------------------------------------- | :--------------------------------------------------------- |
| **工作原理**   | 基于索引和 `length` 属性                   | 基于可迭代协议（Iterator）                                 |
| **处理代理对** | **失败**。会将代理对的每个单元当成独立字符 | **成功**。能自动识别并组合代理对，将其作为一个完整字符返回 |
| **适用场景**   | 当你需要操作字符索引时                     | 当你需要正确遍历并获取字符串中的每一个真实字符时           |

这个例子清晰地表明，**在需要处理可能包含复杂 Unicode 字符（如 Emoji）的字符串时，应当优先使用 `for...of` 循环**，以避免因代理对问题导致的各种奇怪的 bug。
