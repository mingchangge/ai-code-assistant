# ES2020(es11)新特性

## 1. BigInt 类型

**BigInt** 是一种新的原始数据类型，它允许我们表示和操作任意大的整数。在此之前，JavaScript 中的数字类型 (Number) 只能安全地表示介于 -(2^53 - 1) 和 2^53 - 1 之间的整数（即 `Number.MIN_SAFE_INTEGER` 和 `Number.MAX_SAFE_INTEGER`）。超过这个范围的整数在计算时可能会失去精度。BigInt 类型通过在数字后面添加 n 来表示，或者通过调用 `BigInt()` 构造函数来创建。

主要特点：

- **任意精度整数**： 可以表示和操作比 Number 类型支持的最大值更大的整数。
- **使用 n 后缀**： 直接在整数后面加上 n 来创建一个 BigInt。
- **BigInt() 构造函数**： 可以将 Number、字符串或其他 BigInt 转换为 BigInt。
- **与 Number 类型不同**： BigInt 和 Number 类型不能直接混合进行数学运算，需要进行类型转换。
- **支持大多数数学运算符**： +、-、\*、/、%、\*\* 等，但不支持位操作符（&、|、^、~、<<、>>、>>>）以及无符号右移（>>>）。

```javascript
// 使用 n 后缀创建 BigInt
const bigInt1 = 123456789012345678901234567890n

// 使用 BigInt() 构造函数创建 BigInt
const bigInt2 = BigInt('987654321098765432109876543210')

console.log(bigInt1) // 123456789012345678901234567890n
console.log(bigInt2) // 987654321098765432109876543210n
```

应用场景：

- 处理大型 ID 或数据库主键。
- 密码学中的大数运算。
- 金融领域需要精确计算大整数的场景。
- 科学计算中需要高精度整数的场景。

## 2. `globalThis`

**globalThis** 提供了一个标准化的方式来访问全局对象，无论你身处何种 JavaScript 环境（浏览器、Node.js、Web Workers等）。在此之前，访问全局对象需要根据环境使用不同的变量名（如 `window`、`self`、`global`）。

```javascript
console.log(globalThis) // [object Window]
```

## 3. 可选链操作符(Optional Chaining Operator)

**可选链操作符 (Optional Chaining Operator)**: `?.` 是一种新的语法，用于安全地访问嵌套对象的属性，而无需检查每个中间属性是否存在。如果中间属性不存在，表达式将返回 `undefined` 而不是抛出错误。

```javascript
const obj = {
  a: {
    b: {
      c: 42
    }
  }
}

console.log(obj?.a?.b?.c) // 42
console.log(obj?.a?.b?.d) // undefined
console.log(obj?.a?.b?.d?.e) // undefined
```

## 4. 空值合并操作符(Nullish Coalescing Operator) `??`

**空值合并操作符 (Nullish Coalescing Operator)**: `??` 是一种新的逻辑运算符，用于在左侧操作数为 `null` 或 `undefined` 时返回右侧操作数。与逻辑或运算符 (`||`) 不同，`??` **只**在左侧操作数为 `null` 或 `undefined` 时才返回右侧操作数，而不会对其他假值（如 `0`、`''`、`false`）进行判断。

```javascript
const foo = null ?? 'default string'
console.log(foo) // 'default string'
const feature = undefined ?? 'ES2020'
console.log(feature) // 'ES2020'
const bar = 0 ?? 42
console.log(bar) // 0
const baz = '' ?? 'fallback'
console.log(baz) // ''
```
