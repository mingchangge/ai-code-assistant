# text-wrap属性讲解

`text-wrap: balance;` 是 CSS 中的一个文本布局属性，用于优化多行文本的排版平衡，使段落的各行长度更加均匀，避免出现单字成行或某一行明显过短的情况。

### 作用原理：

当文本有多行时，浏览器通常会尽量填充每行空间，导致最后一行可能只有很少的文字（如单个词或字）。`text-wrap: balance` 会让浏览器重新计算换行位置，调整每行的字符数量，使各行长度更接近，从而呈现更美观、易读的排版效果。

### 适用场景：

- 标题或短段落文本（通常 3-4 行以内效果最佳）
- 希望避免文本排版出现"孤行"（最后一行只有少数文字）的情况
- 需要提升长文本块的视觉平衡感和可读性

### 使用示例：

```css
.title {
  text-wrap: balance;
  width: 300px; /* 配合固定宽度更易看出效果 */
}
```

```html
<h2 class="title">
  这是一段需要优化排版的标题文本，希望通过平衡换行让各行长度更均匀
</h2>
```

### 注意事项：

1. 该属性对单行文本无效，仅作用于多行文本
2. 过度使用可能会导致浏览器为了平衡行宽而牺牲单词的自然拆分（如英文单词被拆分到两行）
3. 目前主流浏览器（Chrome 114+、Firefox 117+、Safari 16.4+）已支持，但旧版本浏览器可能需要降级处理
4. 与 `text-align: justify`（两端对齐）不同，`text-wrap: balance` 不会拉伸单词间距，而是通过调整换行位置实现平衡

简单来说，`text-wrap: balance` 是一种"智能换行"机制，让文本排版更优雅，尤其适合注重视觉细节的设计场景。
