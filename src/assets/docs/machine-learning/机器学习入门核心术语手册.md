# 机器学习入门核心术语手册

机器学习是人工智能的核心分支，核心是让计算机通过数据自主学习规律，无需人工编写具体规则就能完成预测、分类等任务。

**核心本质：** 让计算机通过数据自主学习规律，无需人工编写具体规则就能完成预测、分类等任务。

机器学习的核心是 “数据驱动的自主优化”。

- 它摆脱了传统编程 “人工写规则” 的模式，转而让计算机从数据中找规律。
- 最终目标是让模型具备泛化能力，能处理没见过的新数据。

**关键特点：**

- 依赖数据：数据是学习的基础，数据的数量和质量直接决定模型效果。
- 算法支撑：通过逻辑回归、决策树、神经网络等算法，实现对数据规律的提取。
- 迭代优化：模型训练是反复调整参数的过程，直到在任务上达到理想效果。

**常见应用场景：**

- 日常场景：推荐系统（短视频、购物推荐）、语音识别（输入法语音转文字）、垃圾短信过滤。
- 专业场景：医疗诊断（疾病预测）、金融风险评估（信用评分）、自然语言处理（情感分析）。

## 一、基础概念

- **数据集（Dataset）**：用于模型训练、验证和测试的原始数据集合，通常以表格形式呈现，每行代表一个样本，每列代表一个特征（通常以表格或矩阵形式表示，包含特征（输入变量）和目标（输出变量））。
- **样本（Sample/Instance）**：数据集中的单个数据点，是模型学习的基本单位，包含特征和（或）标签信息。
- **特征（Feature/Attribute）**：描述样本的属性或特性，是模型输入的关键信息，如“房价预测”中的“面积”、“地段”等
- **标签（Label/Target）**：样本的输出结果或类别，监督学习中用于指导模型训练，如“垃圾邮件分类”中的“垃圾邮件”、“正常邮件”。
- **归一化 / 反归一化（Normalization/De-Normalization）**：将特征值缩放到一个固定范围（如 [0, 1]），以避免不同特征之间的量纲差异对模型训练的影响。归一化让模型更高效收敛、避免某一特征因数值过大主导训练、提升泛化能力，其可以提高模型的训练效率和预测性能。
- **训练集（Training Set）**：用于模型学习规律的数据集，模型通过对训练集的学习调整自身参数。
- **测试集（Test Set）**：用于评估训练后模型泛化能力的数据集，模型在测试集上的表现指标（如准确率、召回率等）用于评估模型在未见过数据上的预测能力。
- **验证集（Validation Set）**：用于调整模型超参数（如学习率、树的深度、正则化参数等）的数据集，避免模型过拟合，模型在验证集上的表现指标用于选择最优超参数。
- **泛化能力（Generalization Ability）**：模型对未见过的新数据的适应能力，是衡量模型性能的核心指标，泛化能力越强，模型使用性越高。
- **过拟合（Overfitting）**：模型在训练集上表现极好，但对测试集新数据预测效果差，原因是模型过度学习了训练集的噪声和细节，而非核心规律。
- **欠拟合（Underfitting）**：模型未能充分学习训练集的核心规律，在训练集和测试集上表现都较差，通常是模型复杂度不足导致的。
- **损失函数（Loss Function）**：用于衡量模型预测结果与真实标签之间差异的函数，如均方误差（MSE）用于回归任务，交叉熵损失（Cross-Entropy Loss）用于分类任务，模型训练的目标是最小化损失函数。
- **优化器（Optimizer）**：用于调整模型参数以最小化损失函数的算法，如梯度下降（Gradient Descent）、随机梯度下降（Stochastic Gradient Descent）、Adam 优化器等。

## 二、算法分类

### 1.监督学习（Supervised Learning）算法

- 分类算法：用于将样本分配到预定义类别中的算法，输出为离散标签。
  - 逻辑回归（Logistic Regression）：虽名为“回归”，实则是二分类算法，通过Sigmoid函数将输出映射到[0,1]区间，判断样本属于某一类别概率。
  - 决策树（Decision Tree）：以树状结构构件决策规则，每个节点代表一个特征判断，叶子节点代表类别，易于解释。
  - 支持向量机（Support Vector Machine, SVM）：寻找最与分类超平面，使不同类别的样本年个最大，适用于高维数据，可通过核函数处理非线性问题。
  - 神经网络（Neural Network）：由多个决策树组成的集成算法，通过投票或取均值得到最终结果，能降低过拟合风险。
  - 随机森林（Random Forest）
  - 梯度提升树（Gradient Boosting Tree）

- 回归算法：目标是预测连续型输出值。
  - 线性回归（Linear Regression）：假设特征与输出之间存在线性关系，通过最小化均方误差拟合线性模型。
  - 岭回归（Ridge Regression）：在线性回归基础上引入L2正则化项，防止过拟合，约束参数大小。
  - Lasso回归（Lasso Regression）：在线性回归基础上引入L1正则化项，可使部分参数变为0，实现特征选择，同时进行模型压缩。

### 2.无监督学习（Unsupervised Learning）算法

- 聚类算法：将无标签样本分组，使组内样本相似度高，组间样本相似度低。
  - K-均值聚类（K-Means Clustering）：预先指定聚类数量K，通过迭代将样本分配到最近的聚类中心，更新中心位置直至收敛。
  - 层次聚类（Hierarchical Clustering）：构建树形聚类结构，分为自下而上的凝聚型和自上而下的分裂型，根据样本间相似度构建聚类关系，无需预先指定K。
- 将维算法：在保留数据核心信息的前提下，减少特征维度，简化模型计算。
  - 主成分分析（Principal Component Analysis, PCA）：通过线性变换将数据映射到新的低维空间，使第一主成分包含数据最多方差，依次类推。
  - 线性判别分析（Linear Discriminant Analysis, LDA）：通过线性变换将数据映射到新的空间，使不同类别样本在新空间中尽可能分离，同时保持类别内方差最小。
  - t-SNE（t-Distributed Stochastic Neighbor Embedding）：一种非线性降维算法，擅长将高维数据映射到2D或3D空间用于可视化，能更好的暴力局部样本关系。

### 3.强化学习（Reinforcement Learning）算法

- 智能体（Agent）：强化学习中的主体，通过与环境交互学习策略，实现目标。
- 环境（Environment）：强化学习中的外部系统，智能体与环境交互，接收状态反馈和奖励信号。
- 奖励（Reward）：环境对智能体行为的反馈信号（正向/负向），用于指导智能体学习最优策略，通常是一个标量值。
- Q-Learning（Q-Table）：一种基于值迭代的强化学习算法，通过维护一个状态-动作值函数（Q-Table），估计每个状态下每个动作的期望奖励，从而学习最优策略。
- 策略梯度（Policy Gradient）：一种基于策略迭代的强化学习算法，直接优化策略函数，通过梯度上升（或下降）更新策略参数，使策略在环境中获得最大期望奖励。

## 三、常用工具

### 1.编程语言

- **Python**：机器学习最主流的语言，拥有丰富的库和框架，语法简洁易上手。
- **R**：专注于统计分析和数据可视化，在学术研究中应用较广。

### 2.机器学习框架

- **TensorFlow**：Google开发的开源框架，支持静态图和动态图，适用于构建复杂的神经网络模型，如CNN、RNN。
- **PyTorch**：Facebook开发的框架，采用动态图机制，调试方便，灵活性高，深受科研人员和初学者喜爱。
- **Scikit-learn**：Python经典机器学习库，封装了大量传统机器学习算法（如决策树、SVM），API简洁，适合快速实现模型。

### 3.数据处理与可视化库

- **NumPy**：Python的数值计算库，提供高性能的多维数组对象和用于数组操作的函数。
- **Pandas**：数据分析库，提供数据结构（如DataFrame）和数据操作工具，方便数据预处理和分析。
- **Matplotlib**：Python基础绘图库，用于数据可视化，支持绘制折线图、散点图、柱状图等。
- **Seaborn**：基于Matplotlib的统计数据可视化库，提供更美观的图表样式和更高级的统计图表，如热力图、箱线图。

### 4.开发环境

- **Jupyter Notebook/Lab**：交互式计算环境，支持在浏览器中运行代码，支持代码分段执行、添加文本注释和可视化结果，便于调试和文档编写。
- **Visual Studio Code**：轻量级代码编辑器，支持Python、R等语言，提供丰富的插件生态系统，如Jupyter Notebook插件，方便开发和调试。
