`meta name="color-scheme"` 是一个 **HTML 元标签**，用于告知浏览器：当前网页支持哪些颜色方案（如浅色、深色），并建议浏览器优先使用对应方案渲染页面，从而实现网页与系统/浏览器颜色主题的同步适配。

### 一、核心作用：打通网页与系统的「主题协同」

现代操作系统（Windows、macOS、iOS、Android 等）和浏览器都支持「浅色模式」（Light Mode）和「深色模式」（Dark Mode）切换。`color-scheme` 标签的核心价值就是 **建立网页与系统主题的联动**，避免出现「系统是深色，但网页强制浅色（或反之）」的割裂体验。

例如：

- 当用户的系统设置为「深色模式」时，浏览器会优先用网页的深色样式渲染；
- 当用户切换回「浅色模式」时，浏览器自动适配网页的浅色样式。

### 二、语法与取值

#### 1. 基本语法

```html
<meta name="color-scheme" content="取值1, 取值2, ..." />
```

- `name="color-scheme"`：固定属性，声明标签功能；
- `content`：核心属性，指定网页支持的颜色方案（多个取值用逗号分隔，**顺序代表优先级**）。

#### 2. 合法取值

| 取值         | 说明                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| `normal`     | 默认值，网页不主动适配系统主题，浏览器按网页原生样式（未声明主题相关 CSS）渲染 |
| `light`      | 网页支持「浅色模式」，建议浏览器在系统为浅色时使用该方案                       |
| `dark`       | 网页支持「深色模式」，建议浏览器在系统为深色时使用该方案                       |
| `light dark` | 网页同时支持浅色和深色模式（优先浅色，系统深色时自动切换深色）                 |
| `dark light` | 网页同时支持深色和浅色模式（优先深色，系统浅色时自动切换浅色）                 |

### 三、关键特性：与 CSS 的配合

`meta name="color-scheme"` 本身**不直接定义颜色**，它仅向浏览器「声明支持的方案」，真正的颜色样式需要通过 **CSS 媒体查询 `(prefers-color-scheme)`** 来定义。两者必须配合使用才能实现完整的主题适配。

#### 示例：完整的「浅色+深色」适配流程

1. **用 meta 标签声明支持双模式**：

   ```html
   <!-- 网页支持浅色和深色，优先级：浅色→深色 -->
   <meta name="color-scheme" content="light dark" />
   ```

2. **用 CSS 定义两种模式的样式**：

   ```css
   /* 1. 浅色模式样式（默认，或系统为浅色时生效） */
   :root {
     --bg-color: #ffffff; /* 背景白 */
     --text-color: #333333; /* 文字黑 */
   }

   /* 2. 深色模式样式（系统为深色时生效） */
   @media (prefers-color-scheme: dark) {
     :root {
       --bg-color: #1a1a1a; /* 背景深灰 */
       --text-color: #f5f5f5; /* 文字浅灰 */
     }
   }

   /* 应用样式 */
   body {
     background-color: var(--bg-color);
     color: var(--text-color);
     transition: background-color 0.3s; /* 平滑切换 */
   }
   ```

### 四、浏览器兼容性

`color-scheme` 是 **现代浏览器的标准特性**，兼容性良好，主流浏览器均已支持：

- Chrome ≥ 81
- Firefox ≥ 96
- Safari ≥ 13
- Edge ≥ 81
- iOS Safari ≥ 13
- Android Chrome ≥ 81

对于不支持的旧浏览器，标签会被忽略，网页将按默认样式渲染，不会影响功能。

### 五、常见应用场景

1. **通用网站适配**：博客、文档、新闻网站等，通过双模式适配提升用户在不同光线环境下的阅读体验（如夜间用深色模式减少眼部疲劳）。
2. **工具类产品**：编辑器、管理后台等，用户长时间使用时，深色模式可降低视觉负担。
3. **移动端适配**：移动端用户更常切换系统主题，`color-scheme` 可让网页与 App 风格保持一致。

### 六、注意事项

1. **优先级顺序**：`content` 中的取值顺序代表优先级。例如 `content="dark light"` 表示「优先用深色，若系统为浅色则切换浅色」。
2. **避免样式冲突**：若网页已通过其他方式（如自定义主题按钮）实现深色模式，需确保 `color-scheme` 与自定义逻辑不冲突（通常建议以自定义逻辑为准，此时可将 `content` 设为 `normal`）。
3. **测试适配效果**：可通过浏览器开发者工具模拟不同主题（如 Chrome 开发者工具 → More Tools → Rendering → Emulate CSS media feature prefers-color-scheme）。

### 总结

`meta name="color-scheme"` 是实现「网页主题与系统主题同步」的核心标签，它通过向浏览器声明支持的颜色方案，配合 CSS `prefers-color-scheme` 媒体查询，可低成本实现轻量、自然的主题适配，显著提升用户体验。
