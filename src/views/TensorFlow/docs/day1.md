# 线性回归预测房价

在本节中，我们将使用 TensorFlow.js 构建一个简单的线性回归模型，用于预测房价。我们将使用房屋面积作为输入特征，预测对应的房价。

1. 准备工作：
   - 安装 TensorFlow.js 库：`npm install @tensorflow/tfjs`
   - 引入 TensorFlow.js 库：`import * as tf from '@tensorflow/tfjs'`

2. 代码示例：

```tsx
// 线性回归预测房价
import { useEffect, useState, useRef } from 'react'
import { Button, Input, Space } from 'antd'
import * as tf from '@tensorflow/tfjs'

export default function LinearRegressionForPredictingHousePrices() {
  const [area, setArea] = useState('')
  const [price, setPrice] = useState('')
  const modelRef = useRef<tf.Sequential>(null)
  const [loading, setLoading] = useState(false)

  useEffect(() => {
    setLoading(true)
    // 加载 创建模型：单层 Dense（全连接）
    const model = tf.sequential({
      layers: [tf.layers.dense({ units: 1, inputShape: [1] })]
    })
    // 编译模型
    model.compile({
      loss: 'meanSquaredError', // 随机梯度下降
      optimizer: 'sgd' // 均方误差
    })
    modelRef.current = model
    // 训练模型
    async function trainModel() {
      const areaTensor = tf.tensor2d([50, 60, 70, 80, 90, 100], [6, 1])
      const priceTensor = tf.tensor2d([250, 300, 350, 400, 450, 500], [6, 1])
      // 训练模型
      try {
        await model.fit(areaTensor, priceTensor, {
          epochs: 20,
          callbacks: {
            onEpochEnd: (epoch: number, logs: tf.Logs) => {
              console.log(
                `Epoch ${epoch.toString()}: loss = ${logs.loss.toString()}`
              )
            }
          }
        })
        console.log('模型训练完成')
      } catch (error) {
        console.error('模型训练失败', error)
      } finally {
        setLoading(false)
      }
    }
    void trainModel()
  }, [])
  const handlePredict = async () => {
    if (!modelRef.current) {
      console.error('模型未训练完成')
      return
    }
    if (!area) {
      console.error('请输入房屋面积')
      return
    }
    // 调用 TensorFlow 模型进行预测
    const areaTensor = tf.tensor2d([[parseFloat(area)]])
    const priceTensor = modelRef.current.predict(areaTensor)
    const priceValue = (await priceTensor.data()) as Float32Array
    console.log('预测房价', priceValue)
    // 假设模型返回的房价为 1000000 元
    setPrice(priceValue[0].toFixed(2))
  }
  return (
    <div>
      <h1>线性回归预测房价</h1>
      <Space.Compact style={{ width: '100%' }}>
        <Input
          placeholder="请输入房屋面积（平方米）"
          value={area}
          onChange={e => {
            setArea(e.target.value)
          }}
        />
        <Button
          type="primary"
          loading={loading}
          onClick={() => void handlePredict()}
        >
          预测
        </Button>
      </Space.Compact>
      <div>
        <h2>预测结果：</h2>
        <p>房屋面积：{area}平方米</p>
        <p>预测房价：{price}元</p>
      </div>
    </div>
  )
}
```

3. 代码在**epochs=10、15、20+ 出现的不同现象（负数 → 小正数 → NaN）**全是因为**数值不稳定导致的训练崩溃**。
4. 解决方法：
   - 降低 SGD 学习率（需调参），`optimizer: tf.train.sgd(0.0001) // 把默认 0.01 降到 0.0001`,尝试成功！
   - 使用优化器Adam，只使用Adam尝试失败，依旧会出现预测值NaN

# 归一化/反归一化

上面epochs=10、15、20+ 出现的不同现象（负数 → 小正数 → NaN）的核心原因是：**SGD 优化器 + 高学习率 + 大尺度数据 = 梯度爆炸 → 参数发散 → NaN**。

在 TensorFlow.js（其实任何框架）里，一旦权重变成 NaN，此后所有计算都会是 NaN，直到训练结束。

📊 现象与内部状态的对应关系

| Epochs | 表面现象   | 内部发生了什么？                                                                  |
| ------ | ---------- | --------------------------------------------------------------------------------- |
| 10     | 预测为负数 | SGD 刚开始训练，权重被大梯度“推过头”，比如学到 w ≈ -3，所以 101 × (-3) + b < 0    |
| 15     | 预测≈5.2   | 权重在震荡中偶然接近某个小值（如 w≈0.05），但仍是错误方向（正确应≈5）             |
| ≥20    | NaN        | 某次权重更新后，loss 变成 Infinity → 梯度变成 NaN → 所有参数污染为 NaN → 永久失效 |

## 出现NaN的常见原因：

1. 学习率太大

   你给的 SGD 学习率是 0.05，对于“房价”这种绝对数值很大（几十万~上百万）的回归目标，0.05 仍然过大，一步就把权重推到天文数字，第二步直接 overflow → NaN。

2. 初始化 + 激活函数搭配不当

   这里只有一层线性层，初始化默认是 glorotNormal，倒不会直接炸；但只要学习率或标签尺度任意一个失控，线性层也会飞。

   glorotNormal 是 TensorFlow.js（以及其他框架）对**单层线性层的默认权重初始化策略**的正式名称，也叫 **Xavier Normal**，它只有一句话：**“把权重按正态分布随机初始化，使得输出方差 = 输入方差，避免信号爆炸或消失。”**

   一、具体数值怎么来的

   对于全连接层（dense）
   - 输入维度 = fanIn
   - 输出维度 = fanOut

   glorotNormal 把每个权重采样自：`W ~ N(0, σ²)   其中 σ = sqrt(2 / (fanIn + fanOut))`

   在例子中：`model.add(tf.layers.dense({units: 1, inputShape: [1]}))`
   - fanIn = 1
   - fanOut = 1
     ⇒ σ = sqrt(2 / 2) = 1

   于是

   ```plaintext
   w ~ N(0, 1) // 均值 0，标准差 1
   b ~ N(0, 1) // 偏置同样道理
   ```

   **典型初始值大多落在 ±0.1 ~ ±2.0 之间**，极少超过 ±3。

   二、为什么选它
   1. 保持前向/反向传播时方差稳定；
   2. 对线性、tanh、sigmoid这类对称激活效果最好；
   3. 计算简单，只需知道输入输出维度。

   三、与“梯度爆炸”关系
   - glorotNormal 只保证“初始阶段”方差=1；
   - 如果标签绝对值很大（250）而学习率又没降，第一次反向梯度仍可把权重从 ±0.1 推到几百 → 爆炸；
   - 因此它不能替代归一化或调小 lr，只是“起跑线”相对安全。

3. 特征/标签未归一化

下面把“50→250”这一组小数如何一步步把权重推到 Infinity 拆开给你看。

一、模型里到底在算什么

1.  网络结构  
    只有 1 个线性单元：`y_pred = w · x + b`

2.  初始化  
    tf.js 默认用 **glorotNormal**，`w` 初始值 ≈ `N(0, 1/sqrt(1)) ≈ ±0.1` 量级，`b` 同理。

3.  前向传播（第一轮）  
    取第一条样本 `x=50`

    ```
    y_pred = w·50 + b ≈ 0.1*50 + 0.1 = 5.1
    y_true = 250
    loss = (y_pred − y_true)^2 = (5.1 − 250)^2 ≈ 60000
    ```

4.  反向传播——**梯度正比于“残差 × 输入”**

    ```
    d_loss/d_w = 2 · (y_pred − y_true) · x
             ≈ 2 · (−244.9) · 50
             ≈ −24490
    ```

    学习率如果设为 0.01，权重更新量：

    ```
    Δw = −lr · gradient = −0.01 · (−24490) ≈ +244.9
    ```

    于是一步就把 `w` 从 **0.1 → 245**，暴涨 **3 个数量级**。

5.  第二轮再算  
    现在 `w ≈ 245`，`x=50` 给出 `y_pred ≈ 245*50 ≈ 12250`，离 250 更远，残差更大，**梯度爆炸成正反馈**。第三步 `w` 冲到 1e5，第四步 `w` 大到 JavaScript 浮点溢出 → `Infinity`，再下一步 `Infinity*0 = NaN`，loss 变成 NaN。

二、为什么“50”本身不算大，却能把梯度放大

- 爆炸的**核心因子是“残差 × 输入”的绝对值**。  
  250 相对于初始预测 5.1 的残差是 245，再乘以 50，瞬间 1e4 级。  
  只要 **|y_true| ≫ 初始预测**，且 **|x| 也不小**，梯度就会一步飞天。

三、归一化到底缓和了什么

把 `x` 和 `y` 同时压到 **[-1,1]** 后：

- 初始预测 `y_pred = 0.1*0.2+0.1 ≈ 0.12`
- 残差 `≈ 0.2 − 0.12 = 0.08`
- 梯度 `≈ 2*0.08*0.2 = 0.032`
- 更新量 `Δw = 0.01*0.032 = 0.00032`

权重每次只变化 **10⁻⁴** 级，20 个 epoch 稳稳收敛，再也不会 Infinity。

四、一句话总结

**“50”和“250”本身不大，但 250 与初始预测的落差 × 50 的乘积巨大 → 梯度 1e4 级 → 权重一步翻千倍 → Infinity → NaN。**  
 **归一化把落差和输入同时压到 1 级以内，梯度降到 10⁻² 级，爆炸消失。**

## 归一化/反归一化

归一化是将数据映射到统一范围（如 `[0,1]` 或 `[-1,1]`）的预处理操作，反归一化是归一化的逆过程。它的作用是将模型输出的、处于 `[0, 1]` 区间内的预测结果，转换回原始数据的尺度和单位，使其具有实际的、可解释的意义。；二者是机器学习数据预处理的核心步骤，直接影响模型训练效率和预测准确性。

- 1.  归一化（Normalization）

  **定义与核心目的：**
  - 对数据的特征维度进行缩放，消除不同特征间的量纲差异（如 “身高（厘米）” 和 “体重（千克）”）。
  - 核心目的：让模型更高效收敛、避免某一特征因数值过大主导训练、提升泛化能力。

  **常见方法：**
  - 最小-最大归一化（Min-Max Scaling）：
    - 公式：`X_normalized = (X - X_min) / (X_max - X_min)`，适用于数据分布已知的场景。
      - `X` 是原始数据点。
      - `X_min` 是特征维度的最小值。
      - `X_max` 是特征维度的最大值。
    - 作用：将特征值映射到 [0,1] 区间内。
  - 标准归一化（Z-Score Normalization）：
    - 公式：`x_std = (x - μ) / σ`，适用于数据近似正态分布的场景。
    - 作用：将特征值映射到均值为 0，标准差为 1 的正态分布。

- 2. 反归一化（Denormalization）

  **定义与核心目的：**
  - 对归一化后的数据进行逆操作，将其恢复到原始尺度。
  - 核心目的：让模型输出具有实际物理意义，便于解读和应用（如预测房价时，将归一化后的输出还原为真实价格）。

  **操作逻辑：**
  基于归一化时使用的参数（如x_min、x_max或μ、σ）反向计算原始值。

# model.fit()：：让模型通过数据自主学习规律

model.fit 是机器学习（尤其是深度学习）中**模型训练的核心高层 API**，广泛存在于 Keras、TensorFlow、PyTorch Lightning 等框架中。它的核心作用是**自动化驱动模型通过训练数据学习参数**，将 “数据→模型结构” 转化为 “能做预测的有效模型”，是连接数据与模型能力的关键步骤。

**核心定位：模型训练的 “自动化引擎”**

在机器学习中，模型（如神经网络、决策树）的初始参数是随机的，无法直接用于预测。model.fit 的本质是**通过迭代优化算法（如梯度下降），让模型从训练数据中 “学习” 到最优参数**，最终使模型能对新数据做出准确预测。

简单说：没有 model.fit，模型只是一个 “空架子”（参数随机）；通过 model.fit，模型才能 “学会” 规律，具备预测能力。

**工作流程：从 “随机参数” 到 “有效模型”**

`model.fit` 的内部逻辑是对 “前向传播→计算损失→反向传播→更新参数” 的自动化循环，简化流程如下：

1. 初始化：模型参数（如神经网络的权重、偏置）初始化为随机值。

2. 多轮迭代（epochs）：

- 每轮遍历全部训练数据，按 batch_size 拆分成多个批次（batch）；
- 对每个批次：
  - 前向传播：用当前参数计算模型对批次输入 x 的预测值；
  - 计算损失：用损失函数（如交叉熵、均方误差）对比预测值与真实标签 y，得到误差；
  - 反向传播：通过优化器（如 Adam、SGD）计算参数对损失的梯度（影响程度）；
  - 更新参数：根据梯度调整参数（如梯度下降：参数 = 参数 - 学习率 × 梯度），减小损失。

3. 验证（可选）：每轮结束后，用 `validation_data` 评估模型在新数据上的表现（如损失、精度），判断是否过拟合。

4. 结束：达到 epochs 次数或触发回调（如早停）后，返回训练日志（每轮损失、验证指标等）。

## @tensorflow/tfjs的model.fit()

在 `@tensorflow/tfjs`（TensorFlow.js，简称 tfjs）中，`model.fit` 是**模型训练的核心API**，用于在浏览器或 Node.js 环境中驱动模型通过训练数据学习参数。它的核心逻辑与 Python 版 TensorFlow/Keras 的 `model.fit` 一致，但针对 JavaScript 环境做了适配（如异步操作、张量数据处理等），是前端实现机器学习训练的关键方法。

`@tensorflow/tfjs` 是面向 JavaScript 的机器学习库，允许在浏览器或 Node.js 中定义、训练和运行模型。`model.fit` 则是其中“训练模型”的入口：通过接收训练数据（张量形式），迭代优化模型参数，最终让模型学会输入与输出的映射关系。

### 关键特性与参数（与 Python 版的异同）

`tfjs` 的 `model.fit` 继承了 Keras 高层API的简洁性，但因 JavaScript 特性（如异步、张量操作）有细节差异。核心参数如下：

| 参数             | 类型/说明                                                               | 与 Python 版的差异                                                      |
| ---------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `x`              | 训练输入特征，必须是 `tf.Tensor` 或 `tf.Tensor` 数组（多输入模型）。    | 必须是 tfjs 张量（而非 Python 数组），需用 `tf.tensor2d()` 等方法转换。 |
| `y`              | 训练标签，同 `x` 类型（监督学习必需），与 `x` 样本一一对应。            | 同样依赖张量，需保证形状与 `x` 匹配（如 [样本数, 标签维度]）。          |
| `epochs`         | 整数，模型完整遍历训练集的轮次（如 `epochs: 50`）。                     | 含义一致，无差异。                                                      |
| `batchSize`      | 整数，每次参数更新的样本数（默认 32）。                                 | 命名为 `batchSize`（驼峰式），Python 版为 `batch_size`（下划线）。      |
| `validationData` | 验证集数据，格式为 `[xVal, yVal]`（均为张量），用于训练中评估泛化能力。 | 含义一致，但需注意验证集也必须是张量。                                  |
| `callbacks`      | 回调函数对象，用于监控训练过程（如每轮结束后打印日志、保存模型）。      | 支持 `onEpochEnd`、`onBatchEnd` 等回调，可实时更新前端UI（如进度条）。  |
| `verbose`        | 日志输出级别（0=无输出，1=每轮打印进度，2=每轮打印简要信息）。          | 基本一致，1级在浏览器中会显示进度条（类似 Python 终端）。               |

### 核心特点：适配 JavaScript 环境

1. **异步操作**：

   `model.fit` 返回的是 `Promise` 对象（因训练可能耗时，JavaScript 中采用异步处理），必须通过 `await` 或 `.then()` 处理结果。  
   例：`await model.fit(xTrain, yTrain, { epochs: 10 });`

2. **依赖张量（Tensor）**：

   tfjs 中所有数据必须转换为 `tf.Tensor`（张量）才能输入模型（类似 Python 中的 `tf.Tensor`）。普通数组需通过 `tf.tensor2d()`（2D数据）、`tf.tensor3d()`（3D数据）等方法转换。  
   例：将二维数组转为特征张量：

   ```javascript
   const xTrain = tf.tensor2d([
     [1, 2],
     [3, 4],
     [5, 6]
   ]) // 形状 [3, 2]（3个样本，2个特征）
   ```

3. **前端友好的回调**：

   `callbacks` 参数可用于实时更新页面UI（这是浏览器环境的独特优势）。例如，每轮训练结束后在页面显示损失值：

   ```javascript
   model.fit(xTrain, yTrain, {
     epochs: 10,
     callbacks: {
       onEpochEnd: (epoch, logs) => {
         console.log(`第${epoch + 1}轮，损失：${logs.loss}`)
         document.getElementById('loss').innerText =
           `损失：${logs.loss.toFixed(4)}`
       }
     }
   })
   ```

### 执行流程（简化版）

1. **数据准备**：将训练数据（数组）转换为 tfjs 张量（`x` 和 `y`）。
2. **初始化模型**：定义模型结构（如 `tf.sequential()` 构建的序列模型），已编译（指定损失函数、优化器）。
3. **启动训练**：调用 `model.fit(x, y, config)`，内部循环执行：
   - 按 `batchSize` 从 `x` 中取一批样本，前向传播计算预测值；
   - 用损失函数对比预测值与 `y`，计算误差；
   - 反向传播（通过优化器）调整模型参数（权重、偏置）；
   - 每轮结束后，用 `validationData` 评估验证损失/精度（若指定）。
4. **训练结束**：返回包含训练日志（如每轮损失、验证指标）的 `History` 对象。

### 总结

`@tensorflow/tfjs` 的 `model.fit` 是 JavaScript 环境下模型训练的“引擎”，继承了 Keras 易用性的同时，适配了前端的异步特性和张量操作，让开发者能在浏览器或 Node.js 中直接训练模型。其核心价值在于：**降低前端接入机器学习的门槛，支持实时、本地化的模型训练与更新**。

# model.predict()：让模型对新数据生成预测结果

`model.predict()` 是机器学习（尤其是深度学习）模型训练完成后，用于**对新数据生成预测结果**的核心方法，是模型从“训练阶段”走向“应用阶段”的关键接口。它的核心作用是：利用训练好的模型参数（如神经网络的权重、决策树的规则），对输入的未知数据进行计算，输出模型的判断结果（如分类类别、回归值、生成内容等）。

**核心定位：模型的“预测接口”**

训练好的模型（通过 `model.fit` 得到）已经学习了数据中的规律（参数固定），`model.predict()` 则是让模型“发挥作用”的工具——输入新数据，输出模型基于学到的规律做出的“判断”。  
简单说：`model.fit` 是“让模型学会做事”，`model.predict` 是“让学会的模型做事”。

## 输入与输出：严格匹配模型设计

`model.predict()` 的输入和输出格式必须与模型的结构、训练数据的格式严格匹配，否则会报错或输出无意义的结果。

### 1. 输入要求（`x` 参数）

- **数据类型**：通常为数组（如NumPy数组）、张量（如TensorFlow/PyTorch张量）或数据生成器（处理大数据时）。
- **维度匹配**：输入数据的特征维度必须与模型训练时的输入维度一致。  
  例：
  - 若训练时输入是“(样本数, 28, 28, 1)”（28×28的灰度图），则 `predict` 输入也必须是“(N, 28, 28, 1)”（N是待预测样本数）；
  - 若训练时输入是“(样本数, 10)”（10维特征向量），则 `predict` 输入必须是“(N, 10)”。
- **预处理一致**：输入数据需经过与训练数据相同的预处理（如归一化、标准化），否则模型无法正确应用学到的规律。  
  例：训练时用Z-Score标准化（均值μ=5，标准差σ=2），则预测数据也必须用同样的μ和σ处理。

### 2. 输出格式（预测结果）

输出格式由模型的任务类型和输出层设计决定：

- **分类任务**：
  - 若输出层用 `Softmax` 激活，输出为“(N, C)”的概率矩阵（N是样本数，C是类别数），每个元素代表样本属于某一类别的概率（如 `[[0.1, 0.8, 0.1]]` 表示样本有80%概率属于第二类）；
  - 若输出层用 `Sigmoid` 激活（二分类），输出为“(N, 1)”的概率值（如 `[[0.9]]` 表示90%概率属于正类）。
- **回归任务**：  
  输出为“(N, 1)”或“(N, K)”的连续值（K是预测目标数），直接对应预测的物理量（如房价预测输出 `[[58.3]]` 万元）。
- **生成任务**：  
  输出为新的数据（如GAN生成的图像、文本生成模型输出的句子），格式与生成目标一致（如图像生成输出 `(N, 64, 64, 3)` 的RGB图像）。

## 工作原理：仅执行“前向传播”

`model.predict()` 的内部计算逻辑与训练时的“前向传播”完全一致，但**不涉及反向传播和参数更新**（模型参数在训练后已固定）：

1. 输入数据传入模型的输入层；
2. 数据按层传递（输入层→隐藏层→输出层），每层根据训练好的参数（权重、偏置）和激活函数进行计算；
3. 最终从输出层输出计算结果，即预测值。

整个过程是“纯计算”，不改变模型参数，因此可以重复对任意新数据执行预测。

## 关键参数（以Keras/TensorFlow为例）

| 参数名        | 作用与含义                                                                              |
| ------------- | --------------------------------------------------------------------------------------- |
| `x`           | 待预测的输入数据（核心参数），需满足维度和预处理要求。                                  |
| `batch_size`  | 预测时的批次大小（默认32）。大批次可加速计算（利用GPU并行），小批次适合内存有限的场景。 |
| `verbose`     | 日志输出级别（0=无输出，1=显示进度条），预测时通常设为0（避免冗余输出）。               |
| `return_dict` | 布尔值（部分框架支持），是否以字典形式返回结果（方便多输出模型解析）。                  |

## 跨框架差异与共性

- **Keras/TensorFlow**：`model.predict(x)` 是标准API，直接返回预测结果数组，支持批量预测和数据生成器。
- **PyTorch**：原生无 `predict()`，但可通过 `model(x)` 或 `model.forward(x)` 实现相同功能（需注意将数据转换为张量并传入设备）；高层库（如PyTorch Lightning）提供 `predict()` 封装。
- **Scikit-learn**：传统机器学习模型（如 `RandomForestClassifier`）的 `predict(x)` 输出类别标签，`predict_proba(x)` 输出类别概率（对应分类任务）。

**核心共性**：均基于训练好的模型参数，对新数据执行前向计算，输出预测结果。

## 与 `model.evaluate()` 的区别

`model.evaluate()` 用于评估模型在已知标签的测试集上的性能（如计算损失、准确率），而 `model.predict()` 用于对未知标签的新数据生成预测结果。

- 前者需要输入 `(x_test, y_test)`（特征+标签），输出评估指标（如 `loss: 0.2, accuracy: 0.95`）；
- 后者只需输入 `x_new`（仅特征），输出预测结果（如类别、数值）。

## 总结

`model.predict()` 是训练好的模型用于“实际应用”的核心接口，通过前向传播计算，将新输入数据映射为预测结果。它的关键是**输入格式与训练数据一致**（维度、预处理），输出则根据任务类型反映模型的判断（概率、数值、生成内容等）。无论是图像识别、语音翻译还是推荐系统，`model.predict()` 都是模型从“训练完成”到“解决实际问题”的桥梁。

## @tensorflow/tfjs的model.predict()

在 `@tensorflow/tfjs`（TensorFlow.js，用于浏览器和Node.js的机器学习库）中，`model.predict()` 是**训练好的模型对新输入数据进行推断（预测）的核心方法**。它接收输入数据，通过模型的前向传播计算，输出预测结果，是模型从“训练完成”到“实际应用”的关键桥梁。

### 核心作用：从输入到预测结果的“前向传播”

训练好的模型（如神经网络）已经通过 `model.fit()` 学习了数据规律（参数已优化），`model.predict(inputs)` 的作用是：  
**将新的输入数据传入模型，通过模型的层结构（如卷积层、全连接层）进行前向计算，最终输出预测结果**（无需反向传播，仅做推断）。

### 关键细节：输入、输出与使用规则

#### 1. 输入要求：必须是 `tf.Tensor` 且形状匹配

`model.predict()` 的输入必须是 TensorFlow.js 的 **`tf.Tensor` 张量对象**（不能直接传JavaScript数组），且输入形状必须与模型训练时的输入形状一致（除了“样本数维度”可动态变化）。

- **形状匹配规则**：

  假设模型训练时的输入形状为 `[null, 28, 28, 1]`（例如MNIST手写数字识别，`null` 表示样本数可变，`28,28` 是图像尺寸，`1` 是单通道），则预测时输入张量的形状必须是 `[N, 28, 28, 1]`（`N` 是预测的样本数量，可1可多）。

- **输入转换示例**：

  若要预测单张28×28的灰度图，需先将JavaScript数组转为张量并reshape：

  ```javascript
  import * as tf from '@tensorflow/tfjs'

  // 原始输入：28×28的像素数组（0-255）
  const imageArray = new Array(28 * 28).fill(0) // 示例：空白图像
  // 转为张量并调整形状：[1, 28, 28, 1]（1个样本，28×28，单通道）
  const inputTensor = tf
    .tensor2d(imageArray, [28, 28])
    .reshape([1, 28, 28, 1])
    .div(255) // 归一化（与训练时一致）
  ```

#### 2. 输出形式：`tf.Tensor` 张量（需手动转换为JS数据）

`model.predict()` 的输出是 **`tf.Tensor` 张量**，其形状由模型的输出层定义：

- 分类任务（如二分类）：输出可能是 `[N, 1]`（每个样本的类别概率）；
- 多分类任务（如10类分类）：输出可能是 `[N, 10]`（每个样本在10个类别上的概率分布）；
- 回归任务（如房价预测）：输出可能是 `[N, 1]`（每个样本的预测值）。

由于张量是TF.js的特殊对象（需管理内存），通常需要将其转换为JavaScript原生数组/数值后使用，常用方法：

- `tensor.data()`：返回Promise，解析为扁平化的Float32Array（适合小数据）；
- `tensor.array()`：返回Promise，解析为嵌套的JavaScript数组（保留形状）；
- `tensor.dataSync()`/`tensor.arraySync()`：同步获取结果（**不建议在浏览器主线程使用**，可能阻塞UI）。

#### 3. 必须与训练时的预处理一致

预测结果的准确性依赖于“输入数据的预处理逻辑与训练时完全一致”。例如：

- 若训练时对图像做了“归一化到[0,1]”（`x /= 255`），预测时必须同样处理；
- 若训练时对文本做了“词向量+标准化”，预测时也需用相同的词表和标准化参数。

### 与Python TensorFlow的对比

- 相同点：核心逻辑一致，均通过前向传播输出预测结果，依赖输入形状匹配；
- 不同点：
  - 输入输出类型：TF.js中必须用 `tf.Tensor`（Python中可用numpy数组）；
  - 异步特性：TF.js的 `data()`/`array()` 是异步方法（返回Promise），Python中是同步的；
  - 内存管理：TF.js需手动调用 `dispose()` 释放张量内存（Python中自动垃圾回收）。

### 总结

`@tensorflow/tfjs` 的 `model.predict()` 是模型应用的核心接口，负责将新输入的张量通过训练好的模型转换为预测结果张量。其关键是保证输入形状与预处理逻辑和训练时一致，并正确处理输出张量（转换为JS数据+释放内存），是前端/Node.js环境中实现机器学习推断的核心工具。
