### 🟢 第一梯队：核心拿分模块（分值占比最高）

#### 1. 软件工程与系统开发 (约 12-15 分)

**【特点】分值之王，概念多，重题率极高。**

- **开发模型：**
  - **瀑布模型**：线性、文档驱动、需求固定不变、不支持变更，适合需求明确的小项目。
  - **原型模型**：先做原型验证需求，适合**需求不明确、用户交互类**（前端 / UI 类系统最适配）。
  - **增量模型**：分批次交付功能，每增量一个版本可用，适合需求变化频繁的项目。
  - **螺旋模型**：瀑布 + 原型，强调**风险分析**，适合大型复杂项目。
  - **敏捷开发**：Scrum、XP（极限编程），强调适应变化、结对编程。迭代、轻文档、用户参与、拥抱变化，高频考点关键词：自适应、迭代、用户故事。
- **结构化设计：**
  - **模块独立性（必考）**：**高内聚、低耦合**。
    - 内聚 （模块内部，从高到低，越高越好）（好→坏）：功能 > 顺序 > 通信 > 过程 > 时间 > 逻辑 > 偶然。口诀：功信通过时逻偶
    - 耦合（模块间，从低到高，越低越好）（坏→好）：内容 > 公共 > 外部 > 控制 > 标记 > 数据 > 非直接。口诀：非数标控外公内
- **软件测试：**
  - **黑盒测试（功能测试）**：不看代码，只测输入输出，方法：等价类、边界值、错误推测、因果图（不看代码，看功能）。
    - 必考点：边界值分析法是黑盒里用得最多、最有效。边界值分析法（BVA）：测试**边界值**（如：0、1、-1、最大值、最小值、临界值等），发现隐藏的错误。
  - **白盒测试（结构测试）**：看代码逻辑，方法：语句覆盖、判定覆盖、条件覆盖、判定 - 条件覆盖、条件组合覆盖、路径覆盖。
    - 覆盖强度排序：语句 < 判定 < 条件 < 判定 - 条件 < 条件组合 < 路径
  - 测试阶段顺序：单元测试 → 集成测试 → 系统测试 → 验收测试
  - 回归测试：修改 bug 后，重新测试，防止引入新问题
- **软件维护：**
  - 改正性（修Bug）、适应性（升级系统/环境）、完善性（增加新功能，占比最大）、预防性。
- **CMMI（能力成熟度模型）：**
  - 初始级 → 已管理级 → 已定义级 → 量化管理级 → 优化级。

#### 2. 面向对象技术 (约 10-12 分)

**【特点】为下午题打基础，设计模式是重点。**

- **UML图（必考）：**
  - **类图**：静态结构，考关系（依赖、泛化、关联、聚合♢、组合♦）。
  - **用例图**：用户角度，考包含关系（Include）和扩展关系（Extend）。
  - **序列图**：按时间顺序的消息交互。
  - **状态图**：对象的状态变化。
- **面向对象三大特征：** 封装、继承、多态（重载/重写）。
- **设计模式（高频）：**
  - **创建型**：单例（Singleton）、工厂（Factory）、原型（Prototype）。
  - **结构型**：适配器（Adapter，转换接口）、桥接（Bridge，多维度变化）、装饰（Decorator，动态加功能）、组合（Composite，树形结构）。
  - **行为型**：观察者（Observer，一对多联动）、策略（Strategy，算法替换）、状态（State）、命令（Command）。

### 🟡 第二梯队：中坚力量（分值稳定，性价比高）

#### 3. 数据库系统 (约 6-8 分)

**【特点】逻辑性强，规范化理论必考。**

- **三级模式：** 外模式（用户视图）、概念模式（表结构）、内模式（物理存储）。
- **关系代数：** 并、交、差、笛卡尔积、投影（选列）、选择（选行）、连接（Join）。
- **规范化理论：**
  - **1NF**：属性不可再分。
  - **2NF**：消除非主属性对码的**部分依赖**（组合键相关）。
  - **3NF**：消除非主属性对码的**传递依赖**。
  - **BCNF**：消除主属性对码的部分/传递依赖。
- **并发控制：**
  - 问题：丢失更新、读脏数据、不可重复读。
  - 封锁协议：一级（防丢失更新）、二级（防读脏）、三级（防不可重复读）。

#### 4. 计算机网络与信息安全 (约 6-8 分)

**【特点】知识点杂，常考协议和加密。**

- **网络协议：**
  - OSI七层模型 vs TCP/IP四层模型。
  - 常见端口：FTP(20/21), SSH(22), Telnet(23), SMTP(25), DNS(53), HTTP(80), POP3(110), HTTPS(443)。
  - DHCP（自动分配IP）、ARP（IP变MAC）、ICMP（Ping）。
- **网络设备：** 中继器（物理层）、交换机（数据链路层）、路由器（网络层）。
- **信息安全：**
  - **对称加密**：DES, AES, RC4（快，适合大量数据）。
  - **非对称加密**：RSA, ECC（慢，适合小数据、密钥分发）。
  - **数字签名**：**私钥签名，公钥验证**（不可抵赖性）。
  - **攻击类型**：DoS（拒绝服务）、SQL注入（数据库漏洞）、XSS（跨站脚本）。

#### 5. 计算机组成与体系结构 (约 6 分)

**【特点】纯理论部分，计算部分在最后。**

- **数据表示：** 原码、反码、补码、移码的定义。
- **CPU结构：** PC（下条指令地址）、IR（指令内容）、ACC（运算结果）、PSW（状态标志）。
- **体系结构分类（Flynn）：**
  - SISD（单指令单数据）。
  - SIMD（单指令多数据）：**阵列处理机**。
  - MIMD（多指令多数据）：多处理机系统。
- **存储系统：** 局部性原理，Cache映射方式（全相联、直接相联、组相联），Cache淘汰算法。

#### 6. 操作系统 (约 6 分)

**【特点】PV操作逻辑是难点。**

- **进程管理：** 三态转换（就绪、运行、阻塞），死锁的四个必要条件，**前趋图**与PV操作的逻辑对应关系。
- **存储管理：** 页式存储（逻辑地址=页号+页内地址），页面置换算法（LRU, FIFO）。
- **文件管理：** 索引文件结构（直接索引、间接索引），位示图的作用（管理空闲块）。
- **设备管理：** SPOOLing技术（虚拟设备，提高利用率），DMA方式（直接存储器访问，不需要CPU干预）。

### 🔵 第三梯队：辅助模块（难度大或分值少）

#### 7. 数据结构与算法 (约 5-8 分)

**【特点】死记硬背复杂度表。**

- **树与二叉树：** 前序、中序、后序遍历，**哈夫曼树**（最优二叉树）。
- **图：** 邻接矩阵/表，BFS/DFS，最小生成树（Prim, Kruskal）。
- **排序算法时间复杂度（背诵）：**
  - $O(n^2)$：冒泡、选择、直接插入。
  - $O(n \log n)$：**快速排序、归并排序、堆排序**。
- **查找：** 二分查找（有序表）。

#### 8. 程序设计语言与知识产权 (约 5 分)

- **知识产权：**
  - 保护期限：作者终生+50年。
  - 职务作品：利用单位条件+名义→归单位；一般职务作品→归作者（单位有优先使用权）。
  - 侵权判定：善意使用软件（不知情不担责，但须停止使用）。
- **编译原理：** 有限自动机（DFA/NFA），正规式，中间代码（后缀式）。

#### 9. 专业英语 (5 分)

### 🔴 必考计算公式汇总（考前背诵区）

这部分是**必须拿分**的硬通货，只要背下公式套数字即可。

#### 1. 计算机组成原理

- **N进制数值范围（补码）：** $-2^{n-1} \sim 2^{n-1} - 1$ （例如8位是 -128 到 +127）。
- **内存地址计算：**
  - 地址单元数 = $结束地址 - 起始地址 + 1$
  - 芯片数 = $\frac{总容量}{单片容量}$
- **流水线计算：**
  - **公式：** $T = \text{第一条指令执行时间} + (\text{指令条数} - 1) \times \text{流水线周期}$
  - _注：流水线周期 = 各段中执行时间最长的那一段。_
- **系统可靠性：**
  - 串联：$R = R_1 \times R_2 \times \dots$
  - 并联：$R = 1 - (1-R_1) \times (1-R_2) \times \dots$

#### 2. 操作系统

- **逻辑地址转物理地址（页式）：**
  - $\text{物理地址} = \text{物理块号} \times \text{页面大小} + \text{页内偏移量}$
  - _注：考试通常只需找到页号对应的物理块号，直接拼接即可。_
- **磁盘存取时间：**
  - $T = \text{寻道时间} + \text{旋转延迟} + \text{传输时间}$
  - _考点：单缓冲区 vs 双缓冲区的数据处理时间计算。_

#### 3. 计算机网络

- **子网划分（CIDR）：**
  - **网络号** = IP地址 AND 子网掩码
  - **可用主机数** = $2^{\text{主机位数}} - 2$ （减去网络地址和广播地址）

#### 4. 软件工程

- **McCabe环路复杂度（必考）：**
  - 公式1：$V(G) = E - N + 2$ （边数 - 节点数 + 2）
  - 公式2：$V(G) = \text{封闭区域数} + 1$

#### 5. 数据结构

- **数组地址计算（按行/按列存储）：**
  - 需要根据公式推导：$Loc(a_{i,j}) = \text{基地址} + (\text{前面有多少个元素}) \times \text{元素大小}$
- **哈夫曼树带权路径长度 (WPL)：**
  - $WPL = \sum (\text{叶子节点权值} \times \text{路径长度})$
  - _速算方法：所有非叶子节点的权值之和。_
